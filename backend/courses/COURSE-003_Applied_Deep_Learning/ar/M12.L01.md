بنى الدرس السابق تتابع معالجة البيانات. والآن نصل أخيرًا ذلك التتابع بـ model قابل للتدريب.

## مخرجات التعلّم

بنهاية هذا الدرس يجب أن تكون قادرًا على:

- تتبّع شكل tensor عبر أربع كتل التفافية ثلاثية الأبعاد.

- تشخيص اختناقات تحميل البيانات على CPU مقابل حساب GPU.

## 10. الحقول الاستقبالية في 3D

يتيح التفاف `3×3×3` واحد لـ voxel مخرَج واحد أن يعتمد على 27 voxel مُدخَل مجاورًا.

وإذا كدّست التفافين `3×3×3` محشوَّين، يمكن للمخرَج الثاني أن يعتمد على منطقة فعّالة أكبر من المُدخَل الأصلي.

ويصف المصدر الالتفافين المكدَّسين بأن لهما حقلًا استقباليًا فعّالًا `5×5×5` قبل التجميع.

ثم يجمع تجميع الأقصى `2×2×2` المخرَجات المتجاورة ويقلّل الدقة المكانية.

[[IMAGE_NEEDED: Growing 3D receptive field through two convolutions | One deep output voxel traced backward through two 3×3×3 convolution neighborhoods into a larger 5×5×5 source region, followed by 2×2×2 pooling | Learner should notice that small kernels compose into larger effective receptive fields]]

ويعطينا تكديس نوى صغيرة سياقًا أكبر بمعاملات أقل مما يتطلبه التفاف واحد كبير جدًا.

## 26. فخ الدقة: 99.7% صحيحة ومع ذلك عديمة الفائدة

## 27. لماذا يغيّر الاختلال الشديد في توازن الفئات المشكلة

يحتوي توزيع التدريب غير عقيدات أكثر بكثير من العقيدات.

وهذا **لا** يعني أن cross-entropy معطوبة رياضيًا. بل يعني أن إعداد التدريب الكلي يسمح بأن يهيمن حل سهل للفئة الأغلبية على إشارة التعلّم.

ويترك الفصل التصحيح عمدًا للفصل التالي. وهدفنا هنا التعرّف على الإخفاق تعرّفًا دقيقًا.

## 28. تكلفة الخطأ تعتمد على التطبيق

## 29. قد يبقى الـ model يتعلم حتى حين تتعثر الدقة

بعد مزيد من epochs، ما يزال المصدر لا يرى فعليًا أي عيّنة تحقق موجبة مصنَّفة تصنيفًا صحيحًا.

لكن خسارة الفئة الموجبة تبدأ بالانخفاض.

وهذا يخبرنا بشيء دقيق:

- لم تتحسن قرارات التصنيف الصارمة بعد،
- لكن الاحتمالات المتنبَّأ بها قد تتحرك في اتجاه أفضل.

ولهذا يفيد تتبّع **الخسارة والسلوك الخاص بكل فئة**، لا الدقة المعتبَرة بعتبة فقط.

ويمكن للـ model أن يحرز تقدمًا قبل أن يصبح هذا التقدم مرئيًا في مقياس 0/1 خشن.

## 30. مخطط نظام تدريب قابل لإعادة الاستخدام

يعطينا الفصل الكامل هذا النمط:

```text
CONFIGURATION
  وسائط CLI / معرّف التشغيل
        ↓
INITIALIZATION
  device -> model -> optimizer
  Dataset -> DataLoader
        ↓
MODEL
  tail من نوع BatchNorm3d
  كتل Conv3d متكررة
  تسطيح
  head تصنيف خطي
        ↓
TRAINING
  model.train()
  forward -> خسارة لكل عيّنة -> المتوسط
  backward -> optimizer.step()
        ↓
VALIDATION
  model.eval()
  torch.no_grad()
  المقاييس فقط
        ↓
OBSERVABILITY
  مقاييس لكل فئة
  tqdm
  TensorBoard
        ↓
DIAGNOSIS
  كشف اختلال توازن الفئات / الدقة المضلِّلة
```

## مفاهيم خاطئة شائعة

### المفهوم الخاطئ 1: متى وُجدت Dataset مخصصة فلا يضيف DataLoader وظيفة مهمة

يوفّر DataLoader التجميع في دفعات وعمليات workers والتجميع (collation) ودعم pinned memory الاختياري، وكلها مهمة لتدريب كفء.

### المفهوم الخاطئ 2: يمكن أن يدخل اقتطاع CT ثلاثي الأبعاد مباشرةً في `Conv2d`

يستخدم المصدر `Conv3d` لأن العمق والارتفاع والعرض كلها أبعاد مكانية.

### المفهوم الخاطئ 3: ينبغي تمرير احتمالات softmax إلى `CrossEntropyLoss`

يستخدم الفصل logits الخام لـ cross-entropy والاحتمالات منفصلةً لمقاييس التصنيف.

### المفهوم الخاطئ 4: `model.eval()` و`torch.no_grad()` قابلان للتبادل

يغيّر `eval()` سلوك الوحدات؛ ويعطّل `no_grad()` تتبّع التدرّج. ويستخدم التحقق الصحيح كليهما.

### المفهوم الخاطئ 5: دقة تحقق 99.7% تثبت أن المصنِّف ممتاز

dataset شديدة الاختلال في التوازن بحيث إن التنبؤ بكل عيّنة على أنها غير عقيدة قد يحقق هذه الدرجة تقريبًا بينما لا يجد عقيدات تقريبًا.

### المفهوم الخاطئ 6: الخسارة والدقة الكليتان تخبرانك بكل ما يلزم لتصحيح أخطاء الـ model

تكشف الخسائر والتنبؤات لكل فئة سلوكًا قد تخفيه المقاييس المجمَّعة.

### المفهوم الخاطئ 7: إذا لم تتغير الدقة الصارمة فالـ model لا يتعلم شيئًا

يمكن أن تتحسن الاحتمالات والخسارة لكل فئة قبل أن تعبر التنبؤات عتبة التصنيف.

## المصطلحات الأساسية

| المصطلح | المعنى |
|---|---|
| Training application | برنامج منظَّم ينسّق الضبط والبيانات والـ model والتحسين والتحقق والتسجيل. |
| `DataLoader` | أداة PyTorch تجمّع عيّنات dataset في دفعات وتحمّلها، اختياريًا في عمليات worker متوازية. |
| `Conv3d` | التفاف يعمل عبر العمق والارتفاع والعرض. |
| Tail | طبقات الشبكة الأولى التي تكيّف المُدخَل الخام. |
| Backbone | الجسم الرئيسي لاستخلاص features في الشبكة العصبية. |
| Head | الطبقات الأخيرة التي تحوّل features المتعلَّمة إلى مخرَجات المهمة. |
| Receptive field | المنطقة من المُدخَل الأصلي القادرة على التأثير في تنشيط أعمق واحد. |
| Logit | درجة فئة خام قبل softmax. |
| Softmax probability | درجة فئة مطبَّعة غير سالبة مجموع مخرَجاتها 1. |
| Kaiming initialization | تهيئة أوزان مصمَّمة لانتشار إشارة مستقر في الشبكات الشبيهة بـ ReLU. |
| Momentum | آلية في SGD تحمل جزءًا من اتجاه التحديث السابق إلى الخطوات اللاحقة. |
| Per-sample loss (الخسارة لكل عيّنة) | قيمة خسارة منفصلة محتفَظ بها لكل عنصر قبل الاختزال. |
| Boolean mask | tensor صح/خطأ يُستخدم لاختيار مجموعة فرعية من القيم. |
| Class imbalance | أعداد عيّنات غير متساوية بشدة بين الفئات. |
| False negative | عيّنة موجبة جرى التنبؤ بأنها سالبة. |
| `tqdm` | أداة شريط تقدم للكائنات القابلة للتكرار طويلة التشغيل. |
| TensorBoard | أداة تصوير لمقاييس التجارب واتجاهاتها. |
| `SummaryWriter` | واجهة PyTorch لكتابة بيانات أحداث متوافقة مع TensorBoard. |
| Pinned memory | ترتيب لـ memory في CPU قد يحسّن كفاءة النقل من المضيف إلى GPU. |
| DataParallel | غلاف بسيط على جهاز واحد لاستخدام عدة GPUs. |
| DistributedDataParallel | مقاربة PyTorch المقصود بها تدريبًا موزَّعًا أكثر قابلية للتوسع على عدة GPUs. |
