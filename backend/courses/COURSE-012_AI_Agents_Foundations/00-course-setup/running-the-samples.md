# Running samples

Source basis: BOOK-012 Appendix A.

The companion source organizes examples by chapter. A typical local execution pattern is:

```bash
python path/to/example.py
```

For this Masar export, the lesson `.py` files are **curriculum seed files**, not the source book's runnable examples. They hold lesson metadata, Markdown, exercises, quizzes, source mappings, and project links.

Use the source repository or your own implementation repository for runnable agent applications.
