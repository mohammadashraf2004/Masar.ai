## 1. من فهم الصور إلى توليدها

تطرح مهام Computer Vision السابقة أسئلة مثل:

```text
ما هذه الصورة؟
أين يوجد الكائن؟
أي pixels تنتمي إليه؟
```

يضيف generative vision أسئلة جديدة:

```text
هل يمكنني إنشاء صورة جديدة؟
هل يمكنني تغيير هذه الصورة؟
هل يمكنني ملء المحتوى المفقود؟
هل يمكنني ترجمة visual domain إلى آخر؟
هل يمكنني التحكم في geometry أو style أو identity أو semantics؟
```

```text

StyleGAN / GFPGAN
    ↓

    ↓

    ↓

    ↓
توليد وتحرير وتحليل باستخدام اللغة الطبيعية
```

## 2. نماذج GAN الشرطية: التوليد عبر المنافسة

يتكون GAN القياسي من شبكتين.

### المولد (Generator)

يحوّل Generator ضوضاء عشوائية إلى صورة اصطناعية:

```text
z -> G(z)
```

### المميّز (Discriminator)

يقرر Discriminator ما إذا كان الإدخال:

```text
حقيقيًا
أو
مولدًا
```

تتنافس الشبكتان.

كلما أصبح Discriminator أفضل في اكتشاف الصور المزيفة، تلقّى Generator ضغطًا أكبر لإنشاء مخرجات أكثر واقعية.

### لماذا يهم conditioning

يمتلك GAN العادي تحكمًا محدودًا في ما ينشئه.

يضيف conditional GAN شرطًا `y`.

يصبح Generator:

```text
G(z, y)
```

ويقيّم Discriminator:

```text
D(x, y)
```

بالنسبة إلى Fashion-MNIST:

```text
y = shoe, bag, dress, ... — تمثل y الفئة المطلوبة
```

وبذلك يمكن للمتعلم طلب category محددة.

### تمثيلات الفئات (Label embeddings)

يحوّل المصدر class labels إلى vectors متعلَّمة.

مفاهيميًا:

```text
ID الخاص بـ class
   ↓ embedding
تمثيل مستمر لـ class
       +
latent z عشوائي
       ↓
Generator
```

### المميّز الإسقاطي (Projection discriminator)

يستخدم المصدر projection term لقياس مدى التوافق بين image features والـ label المطلوبة.

تتضمن درجة Discriminator فكرتين:

```text
هل هذه الصورة واقعية؟
هل تتطابق هذه الصورة مع الـ class المقدمة؟
```

وهذا أقوى من مجرد سؤال real/fake.

[[IMAGE_NEEDED: Conditional GAN architecture | Show latent z and class label y entering the generator; real/generated images plus the same label entering a projection discriminator with realism + class-compatibility scoring | Learner should understand that conditioning affects both generation and discrimination]]

### تثبيت تدريب GAN في المصدر

يستخدم الفصل عدة تحسينات عملية.

**Spectral normalization**

يقيّد سلوك أوزان Discriminator للمساعدة على استقرار gradients.

**Hinge loss**

يقلل بعض حالات عدم الاستقرار المرتبطة بهدف GAN الأصلي.

**EMA generator**

يحافظ على exponential moving average لمعاملات Generator:

```text
theta_ema — متوسط متحرك أُسّي لمعاملات Generator
=
beta * theta_ema
+
(1-beta) * theta
```

غالبًا ما ينتج EMA model عينات تقييم أكثر استقرارًا.

### مقياس FID

يقارن Fréchet Inception Distance بين feature distributions لكل من:

- الصور الحقيقية،
- الصور المولدة.

التفسير:

```text
FID أقل
-> generated distribution أقرب إلى real distribution
```

لكن المصدر يشير أيضًا إلى أن FID ليس بديلًا مثاليًا عن التقييم البشري.

## 3. Conditional VAE: latent space احتمالية

يدعم Conditional Variational Autoencoder أيضًا التوليد القابل للتحكم، لكنه لا يستخدم adversarial discriminator.

أجزاؤه الثلاثة الرئيسية هي:

```text
المشفّر (Encoder)
إعادة المعلمة (Reparameterization)
فك الترميز (Decoder)
```

### المشفّر (Encoder)

يستقبل Encoder:

```text
الصورة x
+
الـ class y
```

ويتنبأ بـ Gaussian latent distribution:

```text
mu(x,y) — متوسط latent distribution
sigma(x,y) — انحراف latent distribution
```

### حيلة Reparameterization

يمنع random sampling المباشر تدفق gradient بالطريقة المعتادة.

يعيد VAE صياغة sampling بالشكل:

```text
z = — صياغة العينة الكامنة
mu
+
sigma * epsilon

epsilon ~ N(0, I)
```

تُعزل العشوائية داخل `epsilon`، بينما يظل `mu` و`sigma` قابلين للاشتقاق.

### فك الترميز (Decoder)

يستقبل Decoder:

```text
latent z
+
شرط class y
```

ثم يعيد بناء صورة أو يولدها.

### دالة loss في CVAE

يتنافس هدفان:

```text
reconstruction loss — خسارة إعادة البناء
+
beta * KL divergence — حد KL الموزون
```

**Reconstruction**

الحفاظ على وفاء الصورة decoded للبيانات.

**KL regularization**

إبقاء latent distribution قريبة من prior معروف، وغالبًا standard Gaussian.

وهذا يشجع على:

- الاستمرارية،
- smooth interpolation،
- sampling ذي معنى.

[[IMAGE_NEEDED: CVAE architecture | Show image + class label entering encoder → mu/logvar → reparameterization z → decoder + same class label → reconstruction, with reconstruction loss and KL regularization arrows | Learner should understand why the latent space becomes smooth and sampleable]]

### مقارنة cGAN وCVAE

| نموذج cGAN | نموذج CVAE |
|---|---|
| تدريب adversarial | إعادة بناء احتمالية |
| صور غالبًا أكثر وضوحًا | صور غالبًا أكثر نعومة |
| قد يكون التدريب غير مستقر | غالبًا أسهل في optimization |
| قد يحدث mode collapse | latent regularization صريحة |
| هدف قوي للواقعية | latent structure قابلة للتفسير ومستمرّة |

لا يوجد model منهما "أفضل" بصورة مطلقة.

يعتمد الاختيار على ما إذا كانت الأولوية هي:

- perceptual sharpness،
- training stability،
- latent interpretability،
- مرونة conditional control.

## 5. Pix2Pix وCycleGAN: الترجمة بين visual domains

يتعلم image-to-image translation:

```text
صورة المصدر
→ صورة في target domain
```

أمثلة:

- sketch → photograph،
- map → satellite view،
- summer → winter،
- تحويل horse → zebra.

### الترجمة المقترنة (Pix2Pix)

يتطلب Pix2Pix أمثلة paired:

```text
(x, y)
```

حيث يتوافق `x` و`y` مكانيًا.

يجمع هدفه بين:

```text
adversarial loss — الخسارة التنافسية
+
reconstruction loss — خسارة إعادة البناء
```

يشجع adversarial term على الواقعية.

ويشجع reconstruction term على التوافق مع paired target.

### الترجمة غير المقترنة (CycleGAN)

يتعلم CycleGAN من مجموعات unpaired.

لنفترض:

```text
X = صور خيول
Y = صور حُمُر وحشية
```

يتعلم mappingين:

```text
G: X -> Y
F: Y -> X
```

يتطلب cycle consistency:

```text
F(G(x)) ≈ x
G(F(y)) ≈ y
```

يقلل ذلك من احتمال أن يغيّر model المحتوى بصورة عشوائية.

[[IMAGE_NEEDED: Pix2Pix versus CycleGAN | Show paired input-target examples for Pix2Pix with one generator/discriminator path; beside it show unpaired horse/zebra collections with two generators and cycle-consistency loops | Learner should remember paired correspondence versus unpaired reversible translation]]

### المفاضلة الواردة في المصدر

```text
paired data متاحة
-> يستطيع Pix2Pix استخدام correspondence مباشر

paired data غير متاحة
-> يوفر CycleGAN تدريبًا أكثر مرونة
```

قد تؤدي حرية CycleGAN أيضًا إلى:

- texture artifacts،
- تفاصيل دقيقة غير مثالية،
- تغييرات لا يبررها source image بشكل صارم.

## 6. StyleGAN: توليد عالي الدقة وتحكم دلالي

يقدم StyleGAN Generator قائمًا على style مع intermediate latent representation.

يركز المصدر على:

```text
فضاء Z (Z space)
-> mapping network — شبكة التحويل
-> W-style representation — تمثيل style في W
-> layer-wise synthesis — توليد طبقي
```

وهذا يحسن semantic control.

### إصدار StyleGAN3

يركز الفصل على تقليل StyleGAN3 لـ aliasing artifacts.

يتعامل تصميمه مع synthesis بعناية أكبر بوصفه مشكلة signal processing.

يربط المصدر ذلك بـ:

- translation consistency،
- rotation consistency،
- استقرار بنيوي أفضل.

### استيفاء latent (Latent interpolation)

ينتج random seedان نقطتين في latent space.

ينشئ interpolation:

```text
z(alpha) — استيفاء في الفضاء الكامن (latent interpolation)
=
(1-alpha) z1
+
alpha z2
```

تسلسلًا سلسًا من الوجوه الاصطناعية.

### مزج الأنماط (Style mixing)

تتحكم طبقات Generator المختلفة في مستويات مختلفة من abstraction.

يوضح المصدر mixing للـ styles بحيث:

```text
الطبقات المبكرة
-> بنية الوجه الخشنة / pose

الطبقات المتأخرة
-> texture دقيقة / hair / lighting
```

ويوفر ذلك combinations دلالية قابلة للتحكم.

[[IMAGE_NEEDED: StyleGAN latent and style mixing | Show z→mapping→W styles→synthesis layers, plus a grid where row latent controls coarse structure and column latent controls fine appearance | Learner should understand layer-wise semantic control]]

### StyleGANEX وinversion

التوليد من random latent codes هو اتجاه واحد فقط.

يتطلب تحرير الصور الحقيقية:

```text
صورة حقيقية
→ latent representation
→ إعادة بناء عبر Generator
```

وهذا هو GAN inversion.

يستخدم مثال StyleGANEX في المصدر prediction قائمًا على encoder بالإضافة إلى refinement للـ latent/features/noise.

بعد inversion لوجهين حقيقيين، يمكن تنفيذ interpolation بين latent codes الخاصة بهما لإنشاء morphing سلس.

- reconstruction،

## 8. DDPMs: التوليد عبر تعلّم إزالة noise

تستخدم diffusion models فكرة تدريب مختلفة جذريًا عن GANs.

بدلًا من:

```text
latent vector -> image — تحويل مباشر من latent vector إلى صورة
```

في Generator مباشر واحد، تتعلم:

```text
noise -> أنظف قليلًا
     -> أنظف
     -> ...
     -> صورة
```

### الانتشار الأمامي (Forward diffusion)

ابدأ ببيانات نظيفة:

```text
x0
```

ثم أضف Gaussian noise تدريجيًا:

```text
x0 -> x1 -> x2 -> ... -> xT
```

عند `T` كبيرة، تصبح الصورة قريبة من random noise.

تسمح closed-form expression بأخذ عينة من noisy state مباشرة من `x0` باستخدام cumulative noise schedule.

### الانتشار العكسي (Reverse diffusion)

درّب network على توقع noise داخل:

```text
x_t
```

ثم يستخدم scheduler هذا التوقع لحساب state أقل noise.

بدءًا من random noise:

```text
x_T
→ x_(T-1)
→ ...
→ x_0
```

يمكن أن تظهر صورة واقعية.

[[IMAGE_NEEDED: DDPM forward and reverse processes | Show clean image progressively corrupted to Gaussian noise across timesteps, then a U-Net+scheduler iteratively reversing the process from noise back to a synthesized image | Learner should see generation as repeated denoising]]

### لماذا أصبحت diffusion مهمة

يركز المصدر على:

- تدريب مستقر مقارنة بالمنافسة adversarial،
- توليد غني،
- جودة صور عالية.

المفاضلة:

- قد تجعل خطوات denoising الكثيرة sampling مكلفًا حسابيًا.

## 9. Latent diffusion: تنفيذ denoising على تمثيل صورة مضغوط

يكون pixel-space diffusion على الصور عالية الدقة مكلفًا.

تضغط Latent Diffusion Models الصورة أولًا.

```text
الصورة x
  ↓ VAE encoder
latent z
  ↓ diffusion
latent بعد denoising
  ↓ VAE decoder
الصورة
```

### لماذا هو أقل تكلفة

يحتوي latent tensor على قيم أقل بكثير من الصورة الأصلية.

يعطي المصدر الحدس بأن صورة RGB كبيرة يمكن ضغطها بعشرات المرات قبل diffusion.

### ضغط VAE

يتنبأ AutoencoderKL بـ latent distribution.

تُفك شفرة latent sample مرة أخرى إلى صورة.

ينبغي أن تحتفظ reconstruction بمعظم المعلومات البصرية المهمة.

### استيفاء latent (Latent interpolation)

قم بترميز صورتين:

```text
z1, z2
```

ثم نفّذ interpolation:

```text
z(alpha) — استيفاء في الفضاء الكامن (latent interpolation)
=
(1-alpha) z1
+
alpha z2
```

ثم قم بالـ decode.

تُظهر التغييرات السلسة استمرارية ذات معنى في latent space.

## 10. Stable Diffusion: latent denoising مشروط بالنص

يجمع Stable Diffusion عدة modules.

```text
text prompt
  ↓ text encoder
text embedding
         \
random latent noise
     ↓
denoising U-Net + scheduler
     ↓
clean latent
     ↓
VAE decoder
     ↓
الصورة المولدة
```

### الشرط النصي (Text conditioning)

يحوّل text encoder الـ prompt إلى semantic representation.

يتنبأ U-Net بالـ noise وهو مشروط بـ:

- current noisy latent،
- diffusion timestep،
- تمثيل text embedding.

وهذا يجعل reverse process معتمدًا على prompt.

### خطوات Inference

يبدأ التوليد من random latent noise.

تزيل كل reverse step جزءًا من noise المتوقعة.

زيادة عدد الخطوات ليست "أفضل" تلقائيًا لكل model؛ يعتمد النطاق المناسب على scheduler/model المدرَّب.

[[IMAGE_NEEDED: Stable Diffusion architecture | Show text prompt→text encoder, random latent→U-Net denoising loop with scheduler and cross-attention, VAE decoder→image | Learner should understand the four-module latent diffusion pipeline]]

### التحكم عبر Prompt

يؤدي تغيير prompt إلى توجيه التوليد نحو semantic solution مختلفة، بينما تبقى آلية denoising العامة نفسها.

## 11. InstructPix2Pix: تحرير صورة موجودة باستخدام اللغة

يبدأ text-to-image generation من noise.

أما image editing فيبدأ من صورة موجودة.

## 12. ControlNet: فصل semantic intent عن geometry

يصف text prompt ما ينبغي توليده.

- Canny edges،
- depth،
- segmentation map،
- sketch،
- keypoints،

```text

-> semantic change

-> shape / pose / composition

diffusion model
-> النتيجة المدمجة
```

## مفاهيم خاطئة مهمة

### مفهوم خاطئ 1

> Generative AI يعني فقط text-to-image generation.

### لماذا هذا خطأ

يتضمن الفصل conditional generation وtranslation وrestoration وediting وinpainting وsuper-resolution وmultimodal understanding وstructured visual analysis.

### مفهوم خاطئ 2

> Generator في cGAN وحده هو من يقرر ما إذا كانت الصورة تتطابق مع الـ class المطلوبة.

### لماذا هذا خطأ

يُشترط كل من Generator وDiscriminator في المصدر؛ ويقيّم projection discriminator صراحة مدى توافق image-label.

### مفهوم خاطئ 3

> Latent sampling في CVAE يمنع backpropagation.

### لماذا هذا خطأ

يفصل reparameterization trick العشوائية عن distribution parameters القابلة للاشتقاق.

### مفهوم خاطئ 4

> Pix2Pix وCycleGAN يحتاجان النوع نفسه من training data.

### لماذا هذا خطأ

يعتمد Pix2Pix على paired data؛ بينما صُمم CycleGAN لـ unpaired domains.

### مفهوم خاطئ 5

> Latent interpolation هو مجرد pixel blending.

### لماذا هذا خطأ

يحدث interpolation داخل learned representation ثم تُفك شفرتها عبر Generator.

### مفهوم خاطئ 6

> يستطيع GFPGAN إثبات الشكل الأصلي الدقيق لوجه متدهور.

### لماذا هذا خطأ

يعيد generative prior بناء تفاصيل وجه معقولة؛ ولا توجد ضمانة للاستعادة التاريخية الدقيقة.

### مفهوم خاطئ 7

> يولد diffusion صورة في neural-network pass واحدة.

### لماذا هذا خطأ

توليد DDPM القياسي هو reverse-denoising process تكرارية.

### مفهوم خاطئ 8

> Latent diffusion وpixel-space diffusion يحتاجان المستوى نفسه من الحساب.

### لماذا هذا خطأ

يعمل latent diffusion على تمثيل مضغوط، ما يقلل بصورة كبيرة عدد القيم التي يجري عليها denoising.

### مفهوم خاطئ 9

> Stable Diffusion هو U-Net فقط.

### لماذا هذا خطأ

يجمع pipeline الوارد في الفصل بين text encoder وVAE وdenoising U-Net وscheduler.

### مفهوم خاطئ 10

> Text prompts وحدها توفر تحكمًا هندسيًا دقيقًا.

### لماذا هذا خطأ

يوجد ControlNet تحديدًا لإدخال structural constraints صريحة مثل edges وdepth وmasks وposes.

### مفهوم خاطئ 11

> IP-Adapter وControlNet يحلان مشكلة conditioning نفسها.

### لماذا هذا خطأ

يوفر IP-Adapter معلومات appearance من reference image؛ بينما يوفر ControlNet قيود structure/geometry.

### مفهوم خاطئ 12

> Diffusion super-resolution model ينفذ interpolation للـ pixels الموجودة فقط.

### لماذا هذا خطأ

يصفه المصدر بأنه يولد high-frequency detail معقولة.

### مفهوم خاطئ 13

> Inpainting يستعيد pixels المخفية بيقين.

### لماذا هذا خطأ

إنه يولد completion معقولة اعتمادًا على context وpriors.

### مفهوم خاطئ 14

> Vision understanding models وimage-generation models هما المكوّن نفسه.

### لماذا هذا خطأ

يفصل المصدر بين multimodal language models المستخدمة للتحليل وimage-generation/editing models المتخصصة.

### مفهوم خاطئ 15

> يمكن اعتماد المخرجات العلمية أو الطبية المولدة دون تحقق من expert.

### لماذا هذا خطأ

يحافظ المصدر صراحة على الاستخدام الطبي باعتباره غير تشخيصي، ويؤكد أن مراجعة expert تظل ضرورية.

## المصطلحات الأساسية

| المصطلح | المعنى |
|---|---|
| Generative model | Model يتعلم data distribution ويستطيع إنتاج samples جديدة |
| Latent variable | تمثيل مخفي مضغوط يتحكم في المحتوى المولد |
| GAN | framework adversarial قائم على Generator وDiscriminator |
| cGAN | GAN مشروط بـ labels/attributes/text |
| Projection discriminator | Discriminator يستخدم score لتوافق feature-condition |
| Spectral normalization | Weight normalization تُستخدم لتثبيت adversarial training |
| EMA | Exponential Moving Average لمعاملات model |
| FID | مسافة بين feature distributions للصور الحقيقية والمولدة |
| نموذج VAE | نموذج encoder-decoder احتمالي بمتغير كامن |
| CVAE | VAE مشروط بمعلومات class/attribute |
| Reparameterization trick | صياغة differentiable لأخذ latent sample |
| KL divergence | Distribution mismatch term تُستخدم في VAE regularization |
| Pix2Pix | framework للترجمة المقترنة من صورة إلى صورة (image-to-image) |
| CycleGAN | unpaired image-to-image translation مع cycle consistency |
