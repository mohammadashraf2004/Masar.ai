# End-to-End Real-World Data Analysis Capstone

- Frame a business question and success metrics
- Acquire data from at least two source types
- Audit and clean data without overwriting raw inputs
- Perform exploratory and statistical analysis
- Create decision-ready static/interactice visuals
- Use predictive/segmentation/time-series methods only when justified
- Validate all modeling without leakage
- Deliver an executive summary, limitations, and reproducible code
