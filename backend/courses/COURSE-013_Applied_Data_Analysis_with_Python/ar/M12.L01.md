## لماذا يهم هذا الدرس؟

صُممت Artificial Neural Networks (ANNs) و Deep Learning (DL) لتعلّم Representations معقدة مباشرة من البيانات.

يبني الفصل Progression تبدأ من Artificial neuron واحدة وصولًا إلى Architectures متخصصة في Deep Learning:

```text
Artificial neuron (العصبون الاصطناعي)
      ↓
الطبقات والشبكات
      ↓
دوال التنشيط (Activation functions)
      ↓
Optimization + regularization
      ↓
MLP + backpropagation
      ↓
Deep learning
      ↓
CNN
      ↓
RNN
      ↓
LSTM
      ↓
Autoencoders
```

هذه Architectures ليست قابلة للاستبدال فيما بينها.

فكل منها مصمم لأنواع مختلفة من Structure.

```text
أنماط غير خطية جدولية
→ MLP

أنماط مكانية/صورية
→ CNN

أنماط تسلسلية/معتمدة على الزمن
→ RNN / LSTM

تمثيل مضغوط / إعادة بناء
→ Autoencoder
```

الفكرة المركزية التي ينبغي الاحتفاظ بها هي:

> **تتعلم الشبكات العصبية عبر تحويل Inputs خلال Layers ذات Weights، وتطبيق Nonlinear activation functions، وقياس Prediction/Reconstruction error، ثم تحديث Trainable weights بحيث تصبح Loss أصغر.**

تمد Architectures الأعمق في الفصل هذه Mechanism الأساسية بإضافة Structure مناسبة لـ:

- Images،
- Sequences،
- Long-term memory،
- تمثيلات كامنة مضغوطة.

## 1. الشبكات العصبية الاصطناعية

يصف الفصل ANN بأنها Network من Artificial neurons مترابطة.

تستقبل كل Neuron Signals، وتطبق Trainable weights، وتجمع المعلومات، وتضيف Bias، ثم تنتج Output.

شكل مبسط للـ Neuron:

```text
x₁ --× w₁--\
x₂ --× w₂---\
...           → مجموع موزون + bias → تنشيط → مخرج
xₙ --× wₙ---/
```

مفاهيميًا:

```text
z
=
w₁x₁
+
w₂x₂
+
...
+
wₙxₙ
+
b
```

ثم:

```text
المخرج
=
activation(z)
```

## 2. تشريح Artificial neuron

### Inputs

```text
x₁, x₂, ..., xₙ
```

تمثل المعلومات الداخلة إلى Neuron.

---

### Weights

```text
w₁, w₂, ..., wₙ
```

تحدد مدى قوة مساهمة كل Input.

أثناء Learning، يتم تعديل هذه Weights.

---

### Bias

```text
b
```

وتمنح Model Degree of freedom إضافية قابلة للتعلم beyond weighted inputs.

### Weighted signal

قبل Activation:

```text
z = Σ(wᵢxᵢ) + b
```

---

### Activation

```text
إدخال اللاخطية
```

من دون Nonlinear activations، فإن تكديس Layers خطية كثيرة سيظل يتصرف كـ Linear transformation.

## 3. من Neurons إلى Layers

يتم تنظيم Neurons داخل Layers.

### Input layer

تستقبل Features الخاصة بالـ Model.

### Hidden layer

تنفذ Learned transformations.

### Output layer

تنتج Final prediction أو Representation.

تحتوي Deep network على عدة Hidden layers:

```text
Input    # المدخلات
  ↓
Hidden 1    # مخفية 1
  ↓
Hidden 2    # مخفية 2
  ↓
Hidden 3    # مخفية 3
  ↓
Output    # المخرجات
```

تحمل Connections أوزانًا قابلة للتعلم.

ويقوم Training مرارًا بتعديل هذه Weights لتقليل Error.

## 5. Feedforward مقابل Feedback networks

يصنف الفصل Neural networks وفق اتجاه تدفق المعلومات.

### Feedforward network

تتحرك المعلومات:

```text
المدخلات
→ الطبقات المخفية
→ المخرجات
```

لا توجد Recurrent loops.

أمثلة:

- Perceptron،
- Multilayer perceptron.

Tasks مناسبة في المصدر:

- Pattern recognition،
- Classification،
- Regression.

---

### شبكة التغذية الراجعة / المتكررة (Feedback / recurrent network)

تحتوي Recurrent connections.

يمكن أن يعتمد Current computation على:

```text
المدخل الحالي
+
الحالة الداخلية السابقة
```

يربط الفصل هذه Family بـ:

- Sequence learning،
- Time-series forecasting،
- Speech recognition.

RNNs هي المثال الرئيسي على Deep-learning feedback networks لاحقًا في الدرس.

## 6. نماذج تاريخية للشبكات العصبية

يعرض الفصل عدة Milestones.

### McCulloch–Pitts model

- Artificial neuron رياضية مبكرة،
- Binary inputs،
- Weighted sum،
- Thresholded binary output،
- عمليات منطقية بسيطة.

### Hebbian network

تعتمد على تقوية Connections بين Neurons النشطة في الوقت نفسه.

يلخصها المصدر غالبًا بالعبارة:

```text
الخلايا العصبية التي تنشط معًا
ترتبط معًا
```

### Perceptron

- Supervised neural model،
- Weighted inputs،
- Output unit،
- تحديث Weights بناءً على Classification errors،
- محدودة بالمشكلات Linearly separable.

### Adaline

Adaptive Linear Neuron: العصبون الخطي التكيفي.

تستخدم:

- Linear activation،
- تعلّم Delta Rule / LMS.

### Madaline

تجمع عدة Adaline units.

### Multilayer Perceptron

تضيف Hidden layers حتى تتمكن Model من تعلم Nonlinear relationships.

### Backpropagation Network

تستخدم Backward error propagation لتدريب Multilayer networks.

### شبكة Radial Basis Function (دوال الأساس الشعاعية)

تستخدم Radial-basis functions، وغالبًا Gaussian، داخل Hidden layer لمهام مثل:

- Interpolation،
- Function approximation،
- تصنيف الأنماط المحلية.

## 7. لماذا تهم Activation functions؟

تحدد Activation function استجابة Neuron للـ Combined input.

من دون Nonlinear activation:

```text
طبقة خطية
+
طبقة خطية
+
طبقة خطية
=
لا تزال تعيينًا خطيًا
```

مع Nonlinear activation:

```text
الشبكة
→ حدود قرار منحنية
→ تفاعلات خصائص غير خطية
→ تمثيلات أغنى
```

يغطي الفصل:

- Identity،
- Binary Step،
- Bipolar Step،
- Sigmoid،
- Tanh،
- ReLU،
- Leaky ReLU،
- Softmax.

## 8. Identity و Step activation functions

### Identity

```text
f(x) = x
```

Output تساوي Input.

الدور المفيد في المصدر:

```text
طبقة المخرجات للانحدار
```

القيد:

```text
بلا لاخطية
```

---

### Binary step

مفاهيميًا:

```text
x < 0
→ 0

x >= 0
→ 1
```

مفيدة لقرارات Threshold بسيطة.

القيد الرئيسي:

```text
غير قابلة للاشتقاق عند العتبة
الانحدار (gradient) صفري تقريبًا في كل مكان
```

لذلك فهي غير مناسبة لـ Gradient-based backpropagation.

---

### Bipolar step

Outputs:

```text
-1
or
+1
```

وما تزال تعاني القيد نفسه المرتبط بالـ Differentiability.

---

## 9. Sigmoid و Tanh

### Sigmoid

```text
σ(x)
=
1 / (1 + e^(-x))
```

المدى:

```text
0 to 1
```

وهذا مفيد عندما ينبغي أن تتصرف Output كاحتمال.

يربط الفصل Sigmoid بـ:

```text
مخرج التصنيف الثنائي
```

نقاط القوة:

- Smooth،
- Differentiable،
- Nonlinear.

القيود:

- تصبح Gradients صغيرة جدًا مع Extreme inputs،
- Vanishing-gradient problem،
- ليست Zero-centered.

---

### Tanh

مفاهيميًا:

```text
tanh(x)    # الظل الزائدي
```

المدى:

```text
-1 to +1
```

مزاياها مقارنة بـ Ordinary sigmoid في الفصل:

- Zero-centered،
- Derivatives أقوى قرب Origin.

القيد:

```text
لا تزال تعاني تلاشي الانحدارات (vanishing gradients)
عند المدخلات الموجبة/السالبة الكبيرة
```

## 10. ReLU و Leaky ReLU

### ReLU

```text
f(x) = max(0, x)    # دالة ReLU
```

السلوك:

```text
مدخل سالب
→ 0

مدخل موجب
→ دون تغيير
```

نقاط القوة في المصدر:

- Simple،
- Fast،
- تقلل بعض Vanishing-gradient problems،
- تنشئ Sparse activations.

---

### 10.1 Dying ReLU

إذا استقبلت Neuron Inputs بصورة متكررة تبقيها في المنطقة السالبة:

```text
output = 0    # المخرج
```

فقد تتوقف عن المساهمة بفعالية.

يسمي الفصل ذلك:

```text
dying ReLU    # ReLU المحتضرة
```

---

### Leaky ReLU

تسمح بـ Small negative slope.

مفاهيميًا:

```text

=
max(αx, x)    # ReLU المسرَّب
```

## 11. Softmax

تُستخدم Softmax عادةً في Multiclass output.

بالنسبة إلى Logits:

```text
z₁, z₂, ..., zₙ
```

تحولها Softmax إلى Values تحقق:

```text
0 ≤ pᵢ ≤ 1

Σpᵢ = 1
```

مفاهيميًا:

```text
softmax(zᵢ)
=
e^(zᵢ)
/
Σ e^(zⱼ)    # دالة softmax
```

ينتج عن ذلك Probability distribution على Mutually exclusive classes.

مثال:

```text
Airplane → 0.05    # طائرة
Cat      → 0.75    # قطة
Dog      → 0.10    # كلب
Ship     → 0.10    # سفينة
```

Prediction:

```text
Cat    # قطة
```

لأنها تملك أعلى Probability.

## 12. دليل اختيار Activation function

| Activation | الدور الرئيسي في المصدر | ملاحظة مهمة |
|---|---|---|
| Identity | Regression output | لا تضيف Nonlinearity |
| Binary Step | Early perceptrons | لا توجد Gradient مفيدة |
| Bipolar Step | Classical networks | لا توجد Gradient مفيدة |
| Sigmoid | مخرج ثنائي | التشبّع / Vanishing gradient |
| Tanh | طبقات مخفية أقدم | ما تزال Saturate |
| ReLU | طبقات مخفية حديثة | Dying ReLU |
| Leaky ReLU | Hidden layers | اختيار Negative slope |
| Softmax | Multiclass output | يتم تفسير Output vector ككل |

## 14. Regularization

تقلل Regularization الـ Overfitting وتحسن Generalization.

يغطي الفصل:

### L1

تضيف Penalty تعتمد على:

```text
القيم المطلقة للأوزان
```

ويربط المصدر L1 بـ Sparsity و Feature selection.

### L2

تضيف Penalty تعتمد على:

```text
القيم التربيعية للأوزان
```

وتثبط Weights الكبيرة جدًا.

### Dropout

تعطل بعض Neurons عشوائيًا أثناء Training.

ويمنع ذلك Network من الاعتماد المفرط على Paths محددة.

### Early stopping

أوقف Training عندما تتوقف Validation performance عن التحسن أوتبدأ في التدهور.

### Data augmentation

أنشئ Training examples معدلة، خصوصًا للصور:

- Rotations،
- Crops،
- Flips،
- تعديلات أخرى.

### Batch normalization

تقوم بتطبيع Intermediate batch behavior، ويصفها المصدر بأنها تساعد Training على أن تصبح:

- أكثر Stability،
- أسرع،
- وأحيانًا أكثر Regularized.

## 15. Multilayer Perceptron (MLP)

توسع MLP الـ Perceptron عبر إضافة Hidden layer واحدة أوأكثر.

مفاهيميًا:

```text
طبقة المدخلات
    ↓
الطبقة المخفية 1
    ↓
الطبقة المخفية 2
    ↓
طبقة المخرجات
```

تسمح Hidden layers مع Nonlinear activations للـ Model بتعلم Nonlinear relationships.

يصف الفصل الأدوار الأساسية هكذا:

```text
وحدة حسية (Sensory unit)
→ مدخلات

وحدة ربط (Associator unit)
→ مخفية

وحدة استجابة (Response unit)
→ مخرجات
```

يمكن استخدام MLPs في:

- Classification،
- Regression،
- Pattern recognition.

### Decoder

مقابل

## مفاهيم خاطئة مهمة

### المفهوم الخاطئ 1

> «Neuron تجمع Inputs فقط.»

هي تنفذ Weighted sum، وتضيف Bias، ثم تطبق Activation.

### المفهوم الخاطئ 2

> «يمكن لـ Deep stacks من Linear activations تعلم أي Nonlinear pattern.»

من دون Nonlinear activation، تظل Stacked linear layers عبارة عن Linear mapping.

### المفهوم الخاطئ 3

> «Sigmoid هي أفضل Hidden activation لكل Deep network.»

يوضح الفصل أن Sigmoid قد تعاني Vanishing gradients.

### المفهوم الخاطئ 4

> «ReLU لا تملك Failure mode.»

يمكن أن تنتج Dying neurons عندما يهيمن Negative-region behavior.

### المفهوم الخاطئ 5

> «يتم تطبيق Softmax بصورة مستقلة على كل Class.»

Outputs مترابطة لأنها تكوّن Probability distribution واحدة مجموعها 1.

### المفهوم الخاطئ 6

> «Optimizer و Regularization تعنيان الشيء نفسه.»

تقلل Optimization الـ Loss؛ بينما تتحكم Regularization في Complexity/Generalization.

### المفهوم الخاطئ 7

> «Dropout تزيل Neurons بصورة دائمة.»

هي تعطل Units عشوائيًا أثناء Training؛ وهي Mechanism للـ Regularization وقت التدريب.

### المفهوم الخاطئ 8

> «MLP تعني Hidden layer واحدة بالضبط.»

قد تحتوي MLP Hidden layer واحدة أوعدة Layers.

### المفهوم الخاطئ 9

> «Backpropagation عبارة عن Prediction architecture منفصلة لا علاقة لها بـ MLP.»

في المصدر، يستخدم MLP training الـ Backpropagation بالفعل.

### المفهوم الخاطئ 10

> «CNNs توصل كل Image pixel مباشرة بكل Feature detector.»

تستخدم Convolution Local receptive regions و Shared filters.

### المفهوم الخاطئ 11

> «Pooling تنشئ Spatial detail أكثر.»

تقلل Pooling الـ Spatial resolution.

### المفهوم الخاطئ 12

> «Flattening تتعلم Image features.»

تتعلم Convolutional layers الـ Spatial features؛ بينما تعيد Flattening تشكيلها للـ Dense layers.

### المفهوم الخاطئ 13

> «RNN inputs مجرد 2D matrices.»

تتوقع Recurrent layers بنية `(samples, timesteps, features)`.

### المفهوم الخاطئ 14

> «`return_sequences=True` تعني أن Model تتنبأ تلقائيًا بعدة Targets.»

تعني أن Recurrent layer تعيد Outputs لكل Time steps إلى Recurrent layer التالية.

### المفهوم الخاطئ 15

> «LSTM لا علاقة لها بـ RNN.»

LSTM هي Recurrent architecture تحتوي Gated memory.

### المفهوم الخاطئ 16

> «انخفاض RMSE لـ LSTM في المصدر يثبت أن LSTM تتفوق دائمًا على RNN.»

يوضح فقط أن Configuration المقدمة لـ LSTM أدت أفضل في تلك Experiment.

### المفهوم الخاطئ 17

> «Autoencoder تحتاج Class labels.»

يستخدم Reconstruction objective الـ Input نفسها — أونسخة Clean منها — كـ Target.

### المفهوم الخاطئ 18

> «ينبغي أن تبدو Reconstruction أكثر حدة من Original.»

يقول الفصل صراحة إن Reconstructed outputs يمكن أن تكون أكثر Smooth و Blurred.

### المفهوم الخاطئ 19

> «يتم تدريب Denoising autoencoder من Noisy إلى Noisy.»

يتم تدريبها:

```text
مدخل مشوَّش
→ هدف نظيف
```

### المفهوم الخاطئ 20

> «يمكن استخدام Test set مرارًا أثناء Training وتظل Completely untouched test set.»

بمجرد استخدامها للـ Validation monitoring، فهي لم تعد Untouched بالكامل.

## ملاحظات اتساق المصدر

### التوتر بين ANN noise و Data quality

يقول النص المبكر إن ANNs يمكنها تحمل Noisy data و«التعامل بسهولة» مع Quality issues.

لكن الأقسام اللاحقة تقول إن Neural networks تحتاج Numerical non-missing input وأن Performance الخاصة بـ BPN حساسة للـ Noisy أو Inconsistent أو Poorly scaled data.

التفسير المتسق هو:

```text
ANNs تستطيع Modeling لـ Complex/Noisy patterns،
لكنها ما تزال تحتاج Preprocessing
وقد تتضرر من Poor-quality input.
```

### صياغة تاريخ Perceptron

يضع أحد الأقسام التاريخية Perceptron الخاصة بـ Rosenblatt في أواخر الخمسينيات.

لكن قسم MLP يقول لاحقًا إنها قُدمت في 1950.

المصدر غير متسق داخليًا في السنة الدقيقة.

### جملة Hyperparameter عامة في قسم MLP

يناقش المصدر MLP tuning لكنه يذكر لفترة قصيرة Parameters مثل:

```text
عمق الشجرة
عدد المقدِّرات (estimators)
```

وهي تنتمي إلى Tree/Ensemble models وليست `MLPClassifier`.

قائمة Parameters الخاصة بـ MLP التي تأتي مباشرة بعد هذه الجملة هي المقصودة.

### صياغة Keras حول “Input layer”

يقول المصدر إن Keras MLP تحتوي:

```text
6 خلايا عصبية في طبقة المدخلات
```

لكن Code:

⟦CODE_30⟧

تعني أن Input dimension هو عدد Features، بينما `6` هو عدد Units في أول Dense hidden layer.

### رسم Softmax

يضع المصدر Softmax داخل Grid لرسم One-dimensional activation curves.

من الأنسب تفسير Softmax هنا على أنها Vector-valued multiclass output transformation، لا Independent scalar neuron activation.

### Label الخاصة بـ RNN reshape output

بعد Reshape إلى 3D، ما يزال نص Output في المصدر يقول:

```text
الشكل قبل reshape
```

وهذا Typo في Label؛ Code المحيطة تنفذ Reshape بوضوح.

### RNN/LSTM validation leakage

تستخدم كلتا Model ين Sequences التي تم Designate لها مسبقًا بوصفها Test كـ `validation_data` أثناء Training، ثم تحسب Final RMSE عليها.

تظل نتيجة المصدر مفيدة للشرح، لكن Test set ليست Untouched بالكامل.

### عبارة “LSTM overcomes vanishing gradient”

يستخدم المصدر صياغة قوية بأن LSTM «تتغلب» على Vanishing gradients.

يحافظ الدرس على Teaching intention للمصدر: Gated memory مصممة للتعامل مع Long dependencies بصورة أفضل من Basic RNN.

### مصطلحات Autoencoder

يسمي المصدر Autoencoders أسلوب Unsupervised learning ويدرب Reconstruction targets من Input نفسها. أما Denoising version فتستخدم صراحة Noisy input مع Clean input كـ Reconstruction target.
