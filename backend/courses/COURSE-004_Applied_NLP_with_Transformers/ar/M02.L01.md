## 1. ما هو Text Classification؟

يعني Text Classification إسناد نصٍ ما إلى فئة واحدة من مجموعة فئات محددة مسبقًا.

ومن أمثلته:

- تحديد ما إذا كانت رسالة بريد إلكتروني Spam أم لا،
- توجيه تذكرة دعم إلى المسار المناسب حسب اللغة،
- تصنيف ملاحظات العملاء،
- التنبؤ بـ Sentiment،
- اكتشاف Emotion المعبَّر عنها في رسالة.

في مشروع هذا الفصل، يكون الـ Input عبارة عن تغريدة، ويكون الـ Output إحدى فئات المشاعر.

صورة مبسطة لسير العملية:

```text
النص الخام (Raw text)
   ↓
Tokenizer
   ↓
مدخلات رقمية للنموذج
   ↓
DistilBERT
   ↓
طبقة التصنيف (Classification layer)
   ↓
الفئة المتوقعة (Predicted class)
```

يستخدم الفصل DistilBERT، وهو إصدار أصغر وأكثر كفاءة من BERT. الفكرة المهمة ليست اسم الـ Model فقط، بل أننا نبدأ بـ Model تعلّم بالفعل تمثيلات لغوية مفيدة، ثم نكيّفه مع مسألة التصنيف الخاصة بنا.

الـ Checkpoint هو مجموعة الأوزان المدرَّبة مسبقًا والمحفوظة، والتي يتم تحميلها داخل بنية Transformer.

يقدّم الفصل أيضًا ثلاثة أجزاء مهمة من منظومة Hugging Face:

1. Datasets — لتحميل البيانات وفحصها وتحويلها وتقسيمها إلى Batches.
2. Tokenizers — لتحويل النص الخام إلى التمثيل الرقمي الذي يتوقعه الـ Model.
3. Transformers — لتحميل Models مدرَّبة مسبقًا وإجراء Fine-tuning لها أو استخدامها في Inference.

### Padding

تختلف النصوص في أطوالها، بينما تحتاج Neural Network Batches عادة إلى Tensors مستطيلة.

```text
الجملة A -> 6 Tokens
الجملة B -> 10 Tokens
```

يضيف Padding عناصر إلى الـ Sequence الأقصر:

```text
Sentence A -> 6 Tokens حقيقية + 4 PAD Tokens
Sentence B -> 10 Tokens حقيقية
```

### Attention Mask

ينشئ Padding مواضع مصطنعة لا ينبغي أن تسهم مثل النص الحقيقي.

مثال مبسط:

```text
input_ids:
[101, 2009, 2003, 2204, 102,   0,   0]

attention_mask:
[  1,    1,    1,    1,   1,   0,   0]
```

التفسير:

```text
1 -> Token حقيقية من الـ Input
0 -> موضع Padding
```

يستطيع الـ Model استخدام الـ Mask لتجاهل مواضع Padding.

[[IMAGE_NEEDED: Padding and attention mask | Two tokenized sequences of different lengths padded to the same width, with an attention mask showing 1 for real tokens and 0 for padding | Learner should understand that padding fixes tensor shape while the mask prevents PAD positions from being treated as meaningful text]]

### Truncation

إذا تجاوز الـ Input الحد الأقصى لسياق الـ Model، فإن `truncation=True` يقتطع النص إلى طول مقبول.

ولهذا كان فحص طول النص في الخطوة السابقة مهمًا.



## مفاهيم خاطئة مهمة

### المفهوم الخاطئ 1

> Token IDs قيم عددية ذات معنى.

### لماذا هذا خطأ

الـ ID مجرد Index داخل Vocabulary. الفروق الحسابية بين Token IDs لا تعبّر عن تشابه لغوي.

### المفهوم الخاطئ 2

> Validation Accuracy مرتفعة تعني تلقائيًا أن الـ Model جيد.

### لماذا هذا خطأ

يجب تفسير Accuracy إلى جانب Class Balance وBaselines وأنماط Confusion والأخطاء لكل مثال.

### المفهوم الخاطئ 3

> Padding Tokens كلمات عادية ينبغي للـ Model أن يتعلم منها.

### لماذا هذا خطأ

يوجد Padding لجعل Batch Tensors متساوية الطول. ويحدد attention_mask تلك المواضع حتى يمكن تجاهلها.

### المفهوم الخاطئ 4

> Feature Extraction وFine-tuning هما استراتيجية التدريب نفسها.

### لماذا هذا خطأ

في Feature Extraction يبقى الـ Transformer مجمّدًا. أما Fine-tuning فيحدّث الـ Transformer نفسه مع Classification Head.

### المفهوم الخاطئ 5

> إذا كان الـ Model مخطئًا، فلا بد أن تكون المشكلة في الـ Model فقط.

### لماذا هذا خطأ

قد تكشف الأمثلة ذات Loss المرتفعة عن Labels ملتبسة، أو Annotation Errors، أو Data Artifacts غير متوقعة.

## المصطلحات الرئيسية

| المصطلح | المعنى |
|---|---|
| Text Classification | إسناد النص إلى Label واحدة من مجموعة Labels محددة مسبقًا |
| DistilBERT | Transformer أصغر وأكثر كفاءة من عائلة BERT ويُستخدم في الفصل |
| Checkpoint | أوزان مدرَّبة مسبقًا ومحفوظة يتم تحميلها داخل Model Architecture |
| Dataset Split | جزء من البيانات مثل Train أو Validation أو Test |
| Class Imbalance | عدم تساوي عدد الأمثلة بين Target Classes |
| Tokenization | تقسيم/ترميز النص إلى وحدات يستطيع الـ Model التعامل معها |
| Token ID | Integer Identifier خاص بـ Token داخل الـ Vocabulary |
| Subword | Token أصغر من كلمة كاملة لكنه غالبًا أكبر من Character |
| WordPiece | أسلوب Subword Tokenization المستخدم في BERT/DistilBERT Tokenizers |
| `[CLS]` | Special Token يوضع في بداية الـ Sequence في هذا الـ Tokenizer |
| `[SEP]` | Special Token يُستخدم لتحديد فصل/نهاية الـ Sequence |
| `[PAD]` | Padding Token خاص يُستخدم لمساواة أطوال الـ Sequences |
| `input_ids` | Integer Token IDs التي تُمرر إلى الـ Model |
| `attention_mask` | Mask يحدد الـ Tokens الحقيقية مقابل مواضع Padding |
| Hidden State | Vector Representation داخلية ينتجها الـ Transformer |
| Feature Extraction | استخدام تمثيلات Transformer مجمّد كـ Features لمصنّف آخر |
| Fine-tuning | تحديث Parameters الخاصة بالـ Model المدرَّب مسبقًا من أجل Target Task |
| Classification Head | الطبقة النهائية الخاصة بالمهمة والتي تنتج Class Scores |
| Baseline | Model مرجعي بسيط للحكم على مقدار القيمة التي يضيفها الـ Model المدرَّب |
| Confusion Matrix | Matrix تعرض True Classes في مقابل Predicted Classes |
| F1-score | Metric تجمع بين Precision وRecall |
| Error Analysis | فحص Predictions والأمثلة لفهم أنماط الفشل |
