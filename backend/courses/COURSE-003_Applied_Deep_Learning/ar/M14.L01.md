## 1. لماذا لا يكفي التصنيف وحده

يجيب المصنِّف من الفصول السابقة عن:

> **بالنظر إلى اقتطاع هذا المرشَّح، هل هو عقيدة؟**

> **أين ينبغي أن ننظر في CT أصلًا؟**

ولذلك يحتاج المشروع من الطرف إلى الطرف إلى model آخر قبل التصنيف:

```text

   ↓

   ↓
مناطق المرشَّحين
   ↓
التصنيف
   ↓
قرار عقيدة / غير عقيدة
```

## 3. Semantic segmentation وinstance segmentation وobject detection

تجيب هذه المهام عن أسئلة متصلة لكنها مختلفة.

### Semantic segmentation

أسند فئة إلى كل بكسل.

وفي هذا المشروع:

```text
بكسل = مرشَّح عقيدة
أو
بكسل = خلفية / نسيج سليم
```

### Instance segmentation

تفصل الكائنات الفردية من الفئة نفسها.

فعلى سبيل المثال، يمكن تسمية ورمين بوصفهما حالتين (instances) منفصلتين.

### Object detection

تجد الكائنات وتحيطها عادةً بصناديق محيطة (bounding boxes).

[[IMAGE_NEEDED: Semantic segmentation vs instance segmentation vs object detection | One medical-style image shown three times: semantic mask labels all tumor pixels as one class, instance segmentation gives separate IDs to separate tumors, and object detection uses bounding boxes | Learner should distinguish pixel-level categories, object identities, and bounding boxes]]

ويختار الفصل **semantic segmentation** لأن الحاجة الفورية هي قناع على مستوى البكسل للمناطق التي قد تكون مثيرة للاهتمام.

## 4. Segmentation هي تصنيف لكل بكسل

يضغط تصنيف الصور الصورة كلها في تنبؤ فئة واحد أو بضعة تنبؤات.

أما segmentation فتحافظ على البنية المكانية وتتنبأ بفئة لكل موضع في الصورة.

مفاهيميًا:

```text
التصنيف:
صورة H × W -> logits الفئات

التجزئة:
صورة H × W -> خريطة فئات H × W
```

[[IMAGE_NEEDED: Classification versus segmentation output | Same input image feeds two models; classifier returns one class vector, segmenter returns an image-sized mask | Learner should notice that segmentation must preserve location information throughout the network]]

ويؤثر هذا المتطلب بقوة في معمار الـ model: فلا يمكن اختزال النتيجة النهائية في vector فئة عالمي واحد.

### نقطة تحقق تعلّمية 1 — اختر مهمة الرؤية الصحيحة

لكل متطلب، اختر classification أو object detection أو semantic segmentation أو instance segmentation:

1. تحديد هل توجد أي عقيدة في اقتطاع،
2. رسم صندوق واحد حول كل كائن مريب،
3. وسم كل بكسل مريب،
4. التمييز بين الورم A والورم B على مستوى البكسل.

## 5. Segment Anything: model تجزئة عام الغرض

يقدّم الفصل **model Segment Anything (SAM)** الذي أصدرته Meta AI.

وSAM نظام تجزئة يقبل prompts مبني على أفكار transformer.

ويستطيع:

- توليد أقنعة للكائنات في صورة،
- قبول prompts نقطة،
- قبول prompts صندوق،
- قبول prompts قناع،
- التعميم إلى كائنات غير مألوفة دون إعادة تدريب خاصة بالمهمة في أوضاع كثيرة.

ويؤطر الفصل هذا بوصفه **zero-shot segmentation**.

وقدرة SAM الواسعة تجعله مفيدًا نقطة بداية جاهزة رغم أن مجال المشروع — تصوير CT الطبي — يختلف تمامًا عن الصور الفوتوغرافية العادية.

## 6. معمار SAM: image encoder وprompt encoder وmask decoder

ينقسم SAM إلى ثلاثة مكونات رئيسية.

### 1. Image encoder

يستخدم Vision Transformer لتحويل رقعات الصورة إلى features صورة غنية.

### 2. Prompt encoder

يحوّل prompts — النقاط أو الصناديق أو الأقنعة — إلى embeddings.

### 3. Mask decoder

يجمع features الصورة ومعلومات prompt لإنتاج أقنعة التجزئة.

[[IMAGE_NEEDED: SAM architecture | Input image enters a ViT image encoder; point/box/mask prompts enter a prompt encoder; both streams meet in a mask decoder that outputs masks and confidence | Learner should understand the three-component division of SAM]]

ويعيد هذا المعمار استخدام أفكار الفصل 9: تمثيلات token وattention على نمط transformer وخلط المعلومات المتقاطعة.

---

## 7. لماذا يستطيع SAM إرجاع عدة أقنعة

قد يكون prompt ملتبسًا.

فبالنسبة إلى نقطة واحدة على كائن، قد تكون المنطقة المقصودة:

- الكائن كله،
- جزءًا واحدًا ذا معنى،
- أو جزءًا فرعيًا أصغر.

ولذلك يستطيع SAM إرجاع عدة أقنعة مرشَّحة وقيم متعلقة بالثقة.

ويصفها الفصل بأنها غالبًا متداخلة بمقاييس مختلفة.

وهذا درس مهم في أنظمة التجزئة: فـ prompt واحد لا يعرّف دائمًا منطقة صحيحة وحيدة.

## 8. النماذج مفتوحة المصدر تجلب أيضًا مسؤوليات ترخيص

يستخدم الفصل SAM من تنفيذه العام ويناقش الترخيص صراحةً.

دروس مهمة:

- الكود العام ما يزال محميًا بحقوق النشر،
- غياب الترخيص **لا** يعني ملكية عامة،
- قد يكون لكود الـ model والأوزان المدرَّبة مسبقًا شروط ترخيص مختلفة،
- قد تتطلب إعادة التوزيع نسب العمل أو تضمين نص الترخيص.

وهذا جزء من هندسة الإنتاج، لا فكرة قانونية لاحقة اختيارية.

وقبل دمج أي model مدرَّب مسبقًا في منتج حقيقي، افحص ترخيص التنفيذ وشروط الأوزان/البيانات معًا.

## 21. لماذا نجري fine-tuning لـ SegFormer بدلًا من استخدام prompts مع SAM إلى الأبد؟

يتطلب SAM وجود prompt يخبره أين يجزّئ.

لكن الهدف النهائي هو **تجزئة العقيدات التلقائية على شرائح CT غير مرئية دون نقطة تُقدَّم يدويًا**.

ولذلك يستخدم الفصل dataset الصور/الأقنعة التي ولّدها SAM لإجراء fine-tuning لـ **SegFormer**.

وSegFormer model تجزئة دلالية قائم على transformer صُمّم لإنتاج مخرَج تجزئة كثيف بكفاءة.

ويصبح pipeline:

```text
SAM + prompts نقطية معروفة
    ↓
ولّد أقنعة التدريب
    ↓
fine-tuning لـ SegFormer
    ↓
تجزئة تلقائية دون prompts
```

## مفاهيم خاطئة شائعة

### المفهوم الخاطئ 1: التجزئة مجرد تصنيف بفئات أكثر

تختلف التجزئة بنيويًا لأن المخرَج يجب أن يحافظ على التقابل المكاني مع صورة المُدخَل.

### المفهوم الخاطئ 2: object detection وsemantic segmentation قابلتان للتبادل

تنتج detection عادةً صناديق، بينما تتنبأ semantic segmentation بتسميات على مستوى البكسل.

### المفهوم الخاطئ 3: سيكون SAM مثاليًا تلقائيًا على صور CT لأنه foundation model

يناقش الفصل صراحةً فجوة المجال بين pretraining على الصور الطبيعية والتصوير الطبي.

### المفهوم الخاطئ 4: prompt النقطة وقناع التجزئة تمثيل الهدف نفسه

النقطة إرشاد متناثر. والقناع هدف كثيف لكل بكسل.

### المفهوم الخاطئ 5: يعني fine-tuning دائمًا تدريب كل معامل من الصفر

يبدأ fine-tuning من أوزان مدرَّبة مسبقًا ويكيّفها مع المهمة/المجال المستهدف.

### المفهوم الخاطئ 6: معالج صور الـ model كود روتيني اختياري

يفرض المعالج اصطلاحات المعالجة المسبقة مثل تغيير الحجم والتطبيع وصيغة التسميات التي يتوقعها الـ model المدرَّب مسبقًا.

### المفهوم الخاطئ 7: ينبغي أن يجري التحقق تحديثات المُحسِّن إذا كانت الخسارة سيئة

التحقق للقراءة فقط. فهو يستخدم `eval()` و`no_grad()` ولا يحدّث الأوزان أبدًا.

### المفهوم الخاطئ 8: حفظ كائن الـ model كاملًا أفضل دائمًا

يوصي المصدر بحفظ معاملات الـ model عبر `state_dict()` من أجل المرونة.

### المفهوم الخاطئ 9: تحلّ التجزئة محل التصنيف في هذا المشروع

تقترح التجزئة المواضع؛ وما يزال التصنيف يرفض كثيرًا من مناطق المرشَّحين الكاذبة.

## المصطلحات الأساسية

| المصطلح | المعنى |
|---|---|
| Semantic segmentation | إسناد تسمية فئة إلى كل بكسل دون تمييز الحالات المنفصلة. |
| Instance segmentation | تجزئة على مستوى البكسل تميّز حالات الكائنات الفردية. |
| Object detection | تحديد مواضع الكائنات، عادةً بصناديق محيطة. |
| Segmentation mask | خريطة بحجم الصورة تحدد البكسلات المنتمية إلى فئة/منطقة. |
| Segment Anything (SAM) | foundation model للتجزئة قائم على transformer ويقبل prompts. |
| Image encoder | مكوّن SAM الذي يستخلص features الصورة. |
| Prompt encoder | مكوّن SAM الذي يحوّل النقاط أو الصناديق أو الأقنعة إلى embeddings. |
| Mask decoder | مكوّن SAM الذي يجمع تمثيلي الصورة وprompt لتوليد الأقنعة. |
| Zero-shot segmentation (تجزئة دون تدريب إضافي) | تجزئة كائنات/مجالات جديدة دون fine-tuning خاص بالمهمة. |
| Point prompt | إحداثي يُقدَّم لتوجيه التجزئة نحو منطقة اهتمام. |
| Domain gap | الفرق بين بيانات المصدر/pretraining وبيانات المجال المستهدف. |
| Fine-tuning | مواصلة التدريب من أوزان مدرَّبة مسبقًا على dataset خاصة بمهمة/مجال. |
| SegFormer | model تجزئة دلالية قائم على transformer يُستخدم لتجزئة CT دون prompts. |
| AdamW | مُحسِّن من عائلة Adam مع تناقص أوزان مفصول. |
| Image processor | أداة معالجة مسبقة/لاحقة خاصة بالـ model. |
| `state_dict` | تعيين لحالة الـ model المسجَّلة مثل tensors المعاملات المتعلَّمة. |
| Post-processing | تحويل مخرَجات الـ model الخام إلى تنبؤات بحجم الصورة ذات معنى للمهمة. |
