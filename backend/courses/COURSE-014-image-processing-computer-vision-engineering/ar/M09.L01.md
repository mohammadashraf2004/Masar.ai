## 1. تبدأ Restoration بنموذج للتدهور (Degradation model)

تسأل Image enhancement:

> كيف يمكنني جعل هذه الصورة أكثر فائدة أو أكثر إرضاءً بصريًا؟

أما Image restoration فتطرح سؤالًا أكثر صرامة:

> ما العملية التي أدت إلى تدهور الصورة، وكيف يمكنني تقدير الصورة الأصلية التي أنتجت هذه Observation؟

يمثل الفصل المصدر التدهور بالعلاقة:

```text
g = h * f + n
```

حيث:

- `f` هي الصورة الأصلية غير المعروفة،
- `h` هي Degradation function أو Point Spread Function (PSF)،
- `*` ترمز إلى Convolution،
- `n` هي Additive noise،
- `g` هي الصورة المتدهورة المرصودة.

تسعى Restoration إلى تقدير:

```text
f_hat ≈ f
```

### لماذا تُعد هذه Inverse problem؟

العملية الأمامية هي:

```text
صورة نظيفة (clean image)
   ↓ Blur / Degradation
   ↓ Noise
صورة مرصودة (observed image)
```

تحاول Restoration التحرك في الاتجاه المعاكس.

{{image:image-degradation-restoration-model}}

### لماذا تكون المشكلة Ill-posed؟

يصف المصدر المشكلة وفق معنى Hadamard:

- قد لا يوجد Solution وحيد،
- قد تؤدي تغييرات صغيرة في Observation إلى تغييرات كبيرة في Inverse solution،
- قد تكون هناك حاجة إلى Constraints أو Priors إضافية.

يمكن لـ Blur أن يدمر Frequencies أو يضعفها بشدة.

بعد ذلك قد تهيمن Noise على تلك Frequencies نفسها.

ولهذا فإن مجرد "عكس Blur" قد يصبح غير مستقر عدديًا.

### مهام Restoration الأساسية

يذكر الفصل عدة مهام Canonical:

- إزالة الضوضاء (Denoising)،
- إزالة التمويه (Deblurring)،
- ملء المناطق المفقودة (Inpainting)،
- إزالة الضباب/المطر (Dehazing/Deraining)،
- رفع الدقة (Super-resolution).

### Denoising مقابل Deblurring

Denoising تتمثل أساسًا في:

```text
g = f + n
```

أما Deblurring فتتمثل أساسًا في:

```text
g = h * f + n
```

الفرق المهم هو أن Deblurring تحاول عكس Convolutional degradation إلى جانب التعامل مع Noise.

## 2. Inverse filtering: أبسط فكرة لـ Deconvolution

باستخدام Convolution theorem:

```text
G(u,v) = H(u,v) F(u,v) + N(u,v)
```

إذا لم توجد Noise وكانت `H` معروفة:

```text
F_hat = G / H
```

وهذا هو **Inverse filter**.

### لماذا تبدو الفكرة جذابة؟

يضرب Blur طيف الصورة في Transfer function.

لذلك تبدو القسمة على Transfer function كأنها عملية مباشرة لإلغاء التأثير.

### عدم الاستقرار الأساسي

لنفترض أنه عند Frequency معينة:

```text
|H| ≈ 0
```

إذن:

```text
1 / |H| -> very large — يصبح Gain العكسي كبيرًا جدًا
```

أي Noise صغيرة عند تلك Frequency تتضخم بدرجة هائلة.

ولهذا يعمل Inverse filtering بصورة أفضل عندما:

- تكون Blur معروفة بدقة،
- تكون Noise غائبة أو صغيرة للغاية،
- لا تقترب Transfer function من الصفر بصورة شديدة.

## 3. Wiener filtering: إزالة Blur مع مراعاة Noise

يتجاهل Inverse filter البنية الإحصائية للـ Noise.

أما Wiener filter فيوازن صراحةً بين:

- عكس Blur،
- الحد من تضخيم Noise.

يصوغه المصدر بوصفه مقدّر **Minimum Mean Square Error (MMSE)**.

تتضمن صيغة قياسية في Frequency domain:

```text
H*
-------------------------
|H|^2 + S_n / S_f
```

حيث:

- `H*` هي Complex conjugate الخاصة بـ Blur transfer function،
- `S_n` هي Noise power spectral density،
- `S_f` هي Signal power spectral density.

### الفكرة الأساسية

عندما تكون Noise صغيرة:

```text
S_n / S_f -> small — نسبة Noise إلى Signal تكون صغيرة
```

يتصرف Wiener filter بصورة أقرب إلى Inverse filtering.

وعندما تكون Noise قوية:

```text
S_n / S_f -> large — نسبة Noise إلى Signal تكون كبيرة
```

يقمع Filter الـ Frequencies غير الموثوقة بدلًا من تضخيمها.

[[IMAGE_NEEDED: Inverse vs Wiener deconvolution | Show original, blurred+noisy, inverse-filter restoration with amplified noise, and Wiener restoration balancing sharpness and noise | Learner should understand Wiener filtering as regularized statistical inversion]]

### لماذا تكون التطبيقات الواقعية أصعب؟

طيف الصورة الأصلية غير معروف.

والطيف الدقيق للـ Noise غير معروف غالبًا.

لذلك يقدم المصدر **Unsupervised Wiener filtering**، حيث تُقدّر هذه القيم أو نسبتها من Observation المتدهورة.

## 4. Tikhonov regularization والمنظور Bayesian

استراتيجية أخرى هي صياغة Restoration بوصفها Optimization.

بدلًا من حل:

```text
H f = g
```

مباشرة، نحل حلًا توفيقيًا:

```text
مطابقة البيانات (data fidelity)
+
التنظيم (regularization)
```

تأخذ Tikhonov objective الشكل:

```text
||Hf - g||^2 — حد Data fidelity
+
lambda ||L f||^2 — حد Regularization
```

حيث:

- يطلب الحد الأول أن تعيد الصورة المستعادة إنتاج Observation بعد تطبيق Degradation عليها،
- ترمز `L` إلى Prior،
- تتحكم `lambda` في قوة Regularization.

### معنى lambda

```text
lambda صغيرة جدًا (lambda too small)
-> قريبة من Inversion غير المستقرة (close to unstable inversion)
-> تضخيم Noise (noise amplification)

lambda كبيرة جدًا (lambda too large)
-> Smoothing قوي (strong smoothing)
-> فقد التفاصيل (detail loss)
```

وهذه هي موازنة Fidelity مقابل Prior الكلاسيكية.

### Priors ممكنة

إذا كانت:

```text
L = identity — استخدام Identity بوصفها Prior operator
```

فإن Solution تعاقب طاقة الصورة الإجمالية.

أما إذا كانت:

```text
L = gradient operator — استخدام Gradient بوصفه Prior operator
```

فإن Solution تعاقب Roughness.

يربط الفصل هذه الفكرة بأساليب Regularization أوسع مثل:

- نعومة Gradient (Gradient smoothness)،
- عقوبات Laplacian (Laplacian penalties)،
- Priors شبيهة بـ Total variation (Total variation-like priors).

### الصيغة في Fourier domain

مع Circular convolution، تشبه Tikhonov solution البسيطة:

```text
H* — المرافق المركب لـ H
------------------
|H|^2 + lambda — المقام مع Regularization
```

يبدو ذلك مشابهًا لمقام Wiener.

### Wiener مقابل Tikhonov

| Wiener | Tikhonov |
|---|---|
| تقدير إحصائي (Statistical estimation) | تحسين Variational (Variational optimization) |
| يستخدم إحصاءات Signal/Noise أو تقديراتها | يستخدم قوة Regularization صريحة |
| تفسير SNR متكيف مع Frequency | قوة Prior حتمية |
| تفسير MMSE | تفسير MAP تحت Gaussian prior |

### التفسير Bayesian

يقدم المصدر التمييز المفاهيمي الآتي:

```text
Wiener -> MMSE البايزي
Tikhonov -> MAP البايزي
```

يقدّر MMSE الـ Conditional expectation.

أما MAP فيختار الصورة الأكثر احتمالًا وفق Posterior model.

## 5. CLEAN: فك الالتفاف المتناثر الجشع (Greedy sparse deconvolution)

طُورت CLEAN لعلم Radio astronomy.

الـ Prior الأساسي فيها هو:

> يمكن تقريب Scene بواسطة مجموعة Sparse من Point sources.

إذا كانت PSF معروفة، يظهر Point source كنسخة مزاحة من تلك PSF.

ولذلك تُعامل Dirty image المرصودة باعتبارها Superposition من PSFs مزاحة.

### Högbom CLEAN

ابدأ بـ:

```text
المتبقي = الصورة المشوشة
المكوّنات النظيفة = 0
```

ثم كرر:

1. حدّد أقوى Residual peak،
2. سجّل جزءًا من هذه Peak كـ Clean component،
3. اطرح نسخة Scaled و Shifted من PSF،
4. كرر حتى الوصول إلى Threshold أو Iteration limit.

ثم:

```text
الصورة النهائية (final image)
=
restoring_beam * clean_components
+
Residual النهائي (final residual)
```

### Loop gain

يوصي المصدر بـ Gain صغير لتحقيق Stability.

الـ Gain الأصغر:

- يطرح بصورة أكثر تحفظًا،
- يحتاج إلى Iterations أكثر.

### لماذا تعمل CLEAN؟

تطابق شكل PSF بطريقة Greedy.

يربطها المصدر مفاهيميًا بـ **Matching pursuit**:

```text
Dictionary atoms = shifted PSFs — كل Atom تمثل PSF مزاحة
```

في كل Iteration، تختار Algorithm الـ Atom الأكثر مطابقة للـ Residual الحالي.

[[IMAGE_NEEDED: Högbom CLEAN workflow | Show dirty astronomical image, PSF, strongest residual peak selection, subtraction of shifted PSF, accumulated sparse clean components, restoring beam, and final restored image | Learner should understand CLEAN as greedy PSF matching under a sparsity prior]]

### متى تكون مناسبة؟

تكون CLEAN مناسبة خصوصًا عندما:

- يكون Scene من النوع Sparse،
- تكون Objects شبيهة بالنقاط،
- تحتوي PSF على Sidelobes.

وتكون أقل ملاءمة للمشاهد الممتدة والمتغيرة بسلاسة.

## 6. Sparse representations و Dictionary learning

Prior آخر في Restoration هو:

> يمكن غالبًا تمثيل Patches صغيرة من الصور الطبيعية باستخدام عدد قليل فقط من Atoms من Overcomplete dictionary.

بالنسبة إلى Patch محولة إلى Vector وممثلة بالرمز `x`:

```text
x ≈ D alpha — تمثيل Patch تقريبًا باستخدام Dictionary و Sparse coefficients
```

حيث:

- `D` هي Dictionary،
- `alpha` هي Sparse.

### Sparse coding

يستخدم Sparse code عددًا قليلًا فقط من Nonzero coefficients.

المسألة المثالية ذات الطابع Combinatorial صعبة، لذلك يستخدم الفصل **Orthogonal Matching Pursuit (OMP)** كتقريب Greedy.

تكرر OMP ما يلي:

1. تبحث عن Atom الأكثر Correlation مع Residual الحالي،
2. تضيفها إلى Active set،
3. تعيد حساب Coefficients باستخدام Projection،
4. تحدّث Residual.

### Dictionary learning

تتناوب Dictionary learning بين:

```text
ثبّت D (fix D)
-> قدّر Sparse codes

ثبّت Codes (fix codes)
-> حدّث D
```

يسمح ذلك لـ Dictionary بالتكيف مع Structures في الصور مثل:

- الحواف (Edges)،
- القوام (Textures)،
- الأنماط المحلية المتكررة (Repeated local patterns).

### لماذا نستخدم Zero-mean patches؟

يزيل المصدر Mean الخاص بالـ Patch قبل Sparse coding.

وهذا يفصل:

```text
معلومات DC / Brightness
```

عن:

```text
تغير Texture / Structure
```

ويُضاف Mean مرة أخرى بعد Reconstruction.

### إعادة بناء Patches

الـ Workflow هو:

```text
صورة مشوشة (noisy image)
    ↓
استخراج Patches متداخلة (extract overlapping patches)
    ↓
إزالة Mean (zero mean)
    ↓
OMP sparse coding
    ↓
إعادة البناء من Dictionary (dictionary reconstruction)
    ↓
إعادة Means الخاصة بالـ Patches (add patch means back)
    ↓
أخذ Average للـ Patches المتداخلة (overlap-average patches)
    ↓
الصورة المستعادة (restored image)
```

[[IMAGE_NEEDED: Dictionary-learning denoising | Show noisy image, overlapping 8×8 patches, learned dictionary atoms, sparse coefficient vector with few nonzeros, reconstructed patches, and overlap-averaged restored image | Learner should understand sparse restoration as projection onto learned local structure]]

### Trade-offs مهمة

يسلط الفصل الضوء على:

- حجم Patch (Patch size)،
- مقدار Stride/Overlap،
- عدد Atoms،
- مستوى Sparsity،
- بيانات تدريب Dictionary،
- طريقة Aggregation،
- الذاكرة والحساب (Memory and computation).

يمكن لـ Sparsity الأقل أن تنفذ Denoising أقوى، لكنها قد تزيل تفاصيل.

## 7. Priors متعلمة باستخدام NAFNet

تكتب الطرق Classical الـ Prior صراحة.

أما Deep restoration فتتعلم Implicit prior من البيانات.

تتعلم Network:

```text
صورة متدهورة (degraded image)
   -> صورة مستعادة (restored image)
```

من Training examples.

### NAFNet

يقدم المصدر **Nonlinear Activation Free Network (NAFNet)** لـ Denoising.

فكرتها المميزة هي إزالة Standard nonlinear activations مثل ReLU/GELU والاعتماد على:

- Convolution،
- Layer normalization،
- Multiplicative gating،
- بنية Residual/Encoder-decoder.

يصف المصدر Simple gating mechanism تضرب Feature groups في بعضها Element-wise.

### التفسير الإحصائي

بالنسبة إلى Training examples من أزواج Noisy/Clean ومع Squared error، يربط المصدر Learned denoising بمقدّر MMSE قائم على البيانات.

### Workflow لـ Pretrained inference

```text
صورة مشوشة (noisy image)
    ↓ Preprocessing/Tensor conversion
Pretrained NAFNet
    ↓
Tensor مستعاد (restored tensor)
    ↓
Output image
```

يمكن معالجة Inputs كبيرة على هيئة Grids/Patches عند الحاجة.

## 9. DeepFill-style و Diffusion-based inpainting

تملأ Inpainting مناطق الصورة المفقودة أو التالفة.

يقارن الفصل بين أساليب CNN الأقدم مثل DeepFill و Generation المبني على Diffusion.

### DeepFill-style CNN inpainting

يصف المصدر Classic CNN inpainting بأنها تستخدم أفكارًا مثل:

- Encoder-decoder networks،
- Contextual attention،
- تفكير بأسلوب الالتفاف الجزئي/المقيَّد.

نقاط القوة:

- Inference سريع،
- ملء جيد للـ Structured holes.

القيود:

- قد تواجه صعوبة مع Missing content غير المقيد،
- قد تكون أضعف في Global semantic consistency.

### الترميم القائم على Diffusion (Inpainting)

تعامل Diffusion عملية Completion بوصفها Conditional generative sampling.

تزيل Model الـ Noise تدريجيًا من Representation بينما تكون مشروطة بـ:

- Known image،
- Mask،
- وغالبًا Text prompt.

### Forward process

يقدم الفصل الفكرة القياسية:

```text
Latent/Image نظيفة
    ↓ إضافة Noise تدريجيًا (progressive noise)
Latent مشوشة (noisy latent)
```

### Reverse process

تتنبأ Neural network بالـ Noise وتزيله خطوة بخطوة.

تغيّر Text guidance تنبؤ Denoising بحيث يتبع Generated content الـ Prompt بصورة أفضل.

### Masked generation

مبدأ Inpainting الأساسي هو:

```text
المنطقة المعروفة (known region) -> الحفاظ عليها (preserve)
المنطقة المقنعة (masked region) -> توليدها (generate)
```

يشدد المصدر على دقة Mask alignment وتصميم Prompt وعدد Inference steps وقوة Guidance وإدارة Memory وفحص Artifacts.

[[IMAGE_NEEDED: Diffusion inpainting pipeline | Show damaged image, binary mask, encoded latent with masked region noised, text-conditioned denoising UNet, and final completed image | Learner should see that only the masked region should be synthesized while context remains consistent]]

### قيد مهم

المنطقة Generated التي تبدو Plausible ليست مضمونة أن تكون الحقيقة التاريخية.

بالنسبة إلى Forensic أو Scientific exact recovery، قد تكون Generative inpainting غير مناسبة.

## 10. LaMa لملء Large masks

بعد ذلك يقدم الفصل **Large Mask Inpainting (LaMa)**.

صُممت LaMa من أجل:

- ثقوب كبيرة (Large holes)،
- محتوى High-resolution،
- بنية صورة Long-range/Global.

### لماذا قد تعاني Local receptive fields العادية؟

إذا كانت Hole كبيرة، فقد يكون Context الأكثر فائدة بعيدًا عن المنطقة المفقودة.

قد لا ترى Network المحلية فقط قدرًا كافيًا من Scene.

### عمليات Fourier/العامة

يشدد المصدر على استخدام LaMa لعمليات Global ذات طابع Frequency/Fourier لتوفير Effective receptive field كبير.

يساعد ذلك على Modeling:

- الخطوط الطويلة (Long lines)،
- الأنماط المتكررة (Repeated patterns)،
- الإضاءة العامة (Global illumination)،
- الاتساق على مستوى Scene بالكامل (Scene-wide consistency).

### Workflow بسيط لـ Inference

باستخدام Wrapper:

⟦CODE_3⟧

Convention شائع:

```text
White mask -> المنطقة المطلوب ملؤها (region to fill)
Black mask -> المنطقة المطلوب الحفاظ عليها (region to preserve)
```

يوصي المصدر بالتأكد من Exact mask convention الخاصة بالـ Wrapper.

### نقاط القوة والمخاطر

نقاط القوة:

- ثقوب كبيرة (Large holes)،
- اتساق عام (Global coherence)،

- Robustness تجاه Resolution.

- محتوى Hallucinated،
- عدم تطابق Color/Lighting،
- أخطاء Geometry،
- عدم وجود ضمان للحقيقة الدقيقة.

## 11. Diffusion editing باستخدام DiffEdit و DDIM inversion

يميز الفصل **Editing** عن Restoration العادية للمناطق المفقودة.

تغيّر Image editing محتوى محددًا وفق Target instruction.

### Workflow الخاص بـ DiffEdit

يعرض المصدر:

1. تحميل Source image،
2. تحديد Source و Target prompts،
3. إنشاء Semantic mask،
4. عكس الصورة الحقيقية إلى Diffusion latent space باستخدام DDIM inversion،
5. إعادة توليد Masked content نحو Target prompt.

من حيث الفكرة:

```text
الصورة المصدر
    ↓ DDIM inversion
مسار الـ latent
    ↓ قناع دلالي + target prompt
تحرير بالـ diffusion
    ↓
الصورة المحرَّرة
```

### لماذا يهم Inversion؟

لا تكون Real image تلقائيًا على Exact latent trajectory المطلوبة لـ Controlled generation.

تقوم DDIM inversion بعمل Mapping تقريبي لها إلى Latent/Noise trajectory بحيث يمكن لـ Generation اللاحقة الحفاظ على جزء كبير من Original structure.

[[IMAGE_NEEDED: DiffEdit workflow | Show original image, source/target prompts, automatically inferred mask, DDIM inversion to latent space, target-conditioned denoising, and edited output | Learner should understand mask inference and latent inversion as separate steps]]

يقارن المصدر على مستوى عالٍ بين Deterministic DDIM-style inversion و Stochastic DDPM-style diffusion.

## 12. Inpainting و Editing و Retouching عمليات مرتبطة لكنها مختلفة

يمكن لكل هذه العمليات استخدام Generative models، لكن Intent الخاص بها يختلف.

### Inpainting

الهدف:

```text
ملء منطقة داخلية مفقودة/مقنعة
```

الـ Input:

- صورة (Image)،
- Mask صريحة،
- Prompt اختيارية.

### Editing

الهدف:

```text
تغيير محتوى محدد بصورة مقصودة (change selected content intentionally)
```

قد يتضمن Input:

- صورة (Image)،
- Target prompt،
- Mask صريحة أو مستنتجة.

### Retouching

الهدف:

```text
تحسين الصورة الموجودة (refine existing image)
مع الحفاظ على المحتوى الأساسي (while preserving core content)
```

يستخدم الفصل Image-to-image diffusion عند **Low strength**.

Low strength:

- تضيف Noise قليلة،
- تحافظ على Original structure بدرجة أكبر.

Higher strength:

- تسمح بتغييرات Semantic أكبر،
- تنتقل من Retouching باتجاه Editing.

[[IMAGE_NEEDED: Inpainting vs editing vs retouching | Show three branches from one source image: masked hole filling, object replacement via prompt, and low-strength whole-image retouch with mostly preserved structure | Learner should distinguish the task objective, not just the model family]]

## 13. Outpainting: التوليد خارج الإطار الأصلي

توسّع Outpainting الصورة إلى ما وراء حدودها الأصلية.

الـ Workflow هو:

1. إنشاء Canvas أكبر،
2. لصق Original image بداخله،
3. تحديد المناطق الجديدة باستخدام Mask،
4. استخدام Inpainting/Generative model لتوليد المنطقة المضافة.

من حيث الفكرة:

```text
النطاق الأصلي Ω (original domain Ω)
داخل (inside)
النطاق الأكبر Ω' (larger domain Ω')
```

تولد Model:

```text
Ω' - Ω
```

باستخدام:

- Context الأصلي المرئي،
- Text prompt،
- Diffusion prior.

### الفرق عن Inpainting

```text
Inpainting  -> تملأ Holes داخل Original domain
Outpainting -> تنشئ Content خارج Original domain
```

[[IMAGE_NEEDED: Outpainting canvas expansion | Show original image centered in a larger blank canvas, mask over added borders, diffusion generation in the new area, and final extended scene | Learner should see outpainting as inpainting over newly created canvas regions]]

### تنبيه المصدر بشأن Mask

يحتوي الفصل المقدم على أكثر من Mask convention في أمثلته Generative. لأي Library/Pipeline محددة، تحقق مما إذا كان White يعني "Replace" أم "Preserve" قبل تشغيل Inference.

وهذا درس Engineering مهم:

> لا تفترض أن Mask polarity موحدة بين Libraries.

## مفاهيم خاطئة مهمة

### المفهوم الخاطئ 1

> Restoration مجرد اسم آخر لـ Enhancement.

### لماذا هذا خطأ؟

يميز المصدر Restoration من خلال استخدامها Degradation model صريحًا أو ضمنيًا ومحاولتها استعادة الصورة النظيفة الكامنة.

### المفهوم الخاطئ 2

> إذا كانت Blur kernel معروفة، فإن Inverse filtering تحل Deblurring دائمًا.

### لماذا هذا خطأ؟

تجعل قيم Transfer function القريبة من الصفر عملية Inversion غير مستقرة وتضخم Noise.

### المفهوم الخاطئ 3

> Wiener filtering مجرد Sharpening أكثر حذرًا.

### لماذا هذا غير مكتمل؟

Wiener filtering هي Statistical estimator توازن بين Inverse filtering وعدم اليقين في Signal/Noise.

### المفهوم الخاطئ 4

> Regularization لا تفعل سوى جعل Optimization أبطأ.

### لماذا هذا خطأ؟

تعمل Regularization على تثبيت Ill-posed inversion بإضافة Prior assumptions.

### المفهوم الخاطئ 5

> CLEAN أفضل طريقة General-purpose لكل صورة فوتوغرافية بها Blur.

### لماذا هذا خطأ؟

أقوى Prior لديها هي Sparse point-like structure ومكونات بشكل PSF.

### المفهوم الخاطئ 6

> Sparse coding تستخدم كل Dictionary atom بمقدار صغير.

### لماذا هذا خطأ؟

الافتراض الأساسي هو أن كل Patch تستخدم عددًا صغيرًا فقط من Active atoms.

### المفهوم الخاطئ 7

> لم يعد Pretrained restoration model يحتوي على Prior.

### لماذا هذا خطأ؟

الـ Prior ضمنية في Learned parameters و Training distribution.

### المفهوم الخاطئ 8

> Generative inpainting تستعيد Exact missing historical pixels.

### لماذا هذا خطأ؟

هي تولد Plausible content مشروطًا بـ Context وغالبًا Text. وقد لا يكون Generated content موجودًا أصلًا في Scene.

### المفهوم الخاطئ 9

> Inpainting و Editing و Retouching و Outpainting أسماء قابلة للتبادل.

### لماذا هذا خطأ؟

تختلف في Region و Intent ومقدار التغيير المسموح به و Conditioning.

### المفهوم الخاطئ 10

> Mask polarity واحدة في كل Inpainting library.

### لماذا هذا خطأ؟

يمكن لـ APIs مختلفة تعريف دلالات White/Black mask بطرق مختلفة. تحقق دائمًا من Pipeline المحددة.

## المصطلحات الأساسية

| المصطلح | المعنى |
|---|---|
| استعادة الصور (Image restoration) | استعادة Estimate لصورة غير متدهورة من Observation متدهورة جرى Modeling لها |

| مسألة غير جيدة الوضع (Ill-posed) | Problem تفتقر إلى Uniqueness أو Stability أو Constraints كافية |
| دالة PSF | Point spread function تصف استجابة Blur |
| فك الالتفاف (Deconvolution) | عكس Convolutional blur |
| مرشح Inverse filter | Frequency-domain division بواسطة Blur transfer function |
| مرشح Wiener filter | Deconvolution موجهة بـ MMSE توازن بين Blur inversion و Noise |
| كثافة PSD | كثافة الطيف القدري |
| تنظيم Tikhonov regularization | Optimization تجمع Data fidelity مع Quadratic prior |
| معامل Regularization parameter | Weight تتحكم في موازنة Fidelity و Prior |
| تقدير MAP | تقدير الاحتمال اللاحق الأعظم |
| تقدير MMSE | تقدير أدنى متوسط مربع الخطأ |
| خوارزمية CLEAN | فك التفاف متناثر جشع بطرح PSF |
| معامل Loop gain | نسبة Residual peak التي تُطرح في كل CLEAN iteration |
| تمثيل Sparse representation | Approximation تستخدم عددًا قليلًا من Active dictionary atoms |
| تعلم Dictionary learning | Joint estimation للـ Atoms و Sparse codes |
| خوارزمية OMP | المطاردة المتعامدة للتطابق |
| قاموس Overcomplete dictionary | Dictionary تحتوي Atoms أكثر من Signal dimensions |
| شبكة NAFNet | شبكة استعادة صور بلا دوال تنشيط غير خطية |
| نموذج InstructIR | نموذج استعادة صور مشروط بالتعليمات |
| عملية Inpainting | ملء مناطق الصورة المفقودة/المقنعة |
| أسلوب DeepFill | نهج inpainting دلالي من عائلة CNN |
| معمارية LaMa | Large-mask inpainting architecture تستخدم Global/Fourier operations |
| نموذج Diffusion model | Generative model قائم على Progressive noising و Learned denoising |
| توجيه Classifier-free guidance | دمج Conditional/Unconditional predictions لتقوية Prompt guidance |
| عملية DDIM inversion | Approximate mapping لصورة حقيقية إلى Diffusion latent trajectory |
| أسلوب DiffEdit | Prompt-based diffusion editing باستخدام Inferred masks |
| عملية Retouching | Refinement مع الحفاظ بدرجة كبيرة على Source content |
| عملية Outpainting | توليد Plausible content خارج Original image frame |
