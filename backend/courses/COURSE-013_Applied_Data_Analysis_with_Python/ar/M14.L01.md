## لماذا يهم هذا الدرس؟

الصور ليست مجرد Pictures.

بالنسبة إلى Python، الصورة عبارة عن بيانات رقمية مرتبة على Grid.

يمكن تمثيل الصورة الملونة بالشكل التالي:

```text
الارتفاع × العرض × عدد Channels
```

ويخزن كل Pixel قيم Intensity أو Color.

وهذا يعني أن Image analysis يمكن التعامل معها كـ Workflow رقمية منظمة:

```text
قراءة الصورة
   ↓
فهم Shape / Channels / dtype
   ↓
تغيير الحجم وتوحيد Geometry
   ↓
العمل داخل Color spaces مناسبة
   ↓
إزالة Noise
   ↓
محاذاة الصورة / تحويلها
   ↓
تحسين Structures المفيدة
   ↓
اكتشاف Edges / Corners / Contours
   ↓
تحويل Visual structure إلى Measurements
   ↓
استخدام Descriptors أو Detectors في المراحل اللاحقة
```

يركز الفصل على ثلاثة مجالات عامة:

```text
أساسيات Image preprocessing
تحويل الصور وتحسينها
اكتشاف Features
```

الفكرة الرئيسية هي:

> **يبدأ Image analysis الموثوق بالتمثيل الصحيح. يؤثر ترتيب Channels و dtype ونطاق Values وحجم الصورة و Interpolation و Color space و Noise والمحاذاة الهندسية جميعها في Measurements و Features التي تستخرجها لاحقًا.**

## 8. dtype الخاصة بالصورة

تستخدم الصورة المحملة عادةً بواسطة OpenCV:

```text
uint8 — نوع البيانات
```

وهذا يخزن قيم Unsigned 8-bit integer:

```text
0 to 255
```

تكون `uint8` مناسبة من أجل:

- Storage،
- العرض العادي (Normal display).

لكن بعض عمليات Image processing تكون أسهل وأكثر أمانًا باستخدام Floating-point values.

---

## 9. لماذا يمكن أن تكون حسابات `uint8` خطرة؟

يحذر الفصل من:

### تجاوز النطاق (Overflow)

لا يمكن تمثيل Values التي تتجاوز النطاق الصالح بصورة طبيعية داخل Unsigned 8-bit integer.

### التقريب / القص (Rounding / clipping)

قد تفقد Intermediate values الكسرية أوالسالبة معلومات إذا تم تحويلها مجددًا إلى Integer range غير مناسب.

يهم ذلك في Operations مثل:

- Smoothing،
- Averaging،
- Sharpening،
- تعديل Exposure.

## 11. طابِق dtype مع نطاق Values

```text

```

```text
يُتوقع عادةً أن تكون حول

```



## 21. فضاء HSV

تفصل HSV بين:

### Hue — نوع اللون

```text
نوع Color
```

### Saturation — تشبع اللون

```text
شدة Color / Vividness
```

### Value — السطوع

```text
Brightness — السطوع
```

يذكر Source conventions الخاصة بـ OpenCV floating-point HSV:

```text
H — Hue — درجة اللون

S — Saturation — تشبع اللون
→ 0–1

V — Value — السطوع
→ 0–1
```
