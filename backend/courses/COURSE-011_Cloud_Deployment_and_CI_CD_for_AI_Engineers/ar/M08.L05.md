## 2. يحتاج Jenkins إلى حالة دائمة

Jenkins ليس خدمة مؤقتة بلا حالة.

فأثناء الإعداد الأولي ينشئ:

- الإعدادات،
- الإضافات (plugins)،
- المستخدمين،
- حالة المهام،
- الأسرار.

وإذا كان كل ذلك داخل نظام ملفات الحاوية فقط، فإن إزالة الحاوية قد تزيل حالة Jenkins.

لذلك يربط المصدر مجلدًا على المضيف بحاوية Jenkins.

من الناحية المفاهيمية:

```text
مضيف EC2
jenkins/var/jenkins_home
        ⇅
حاوية Jenkins
/var/jenkins_home
```

هذا نمط volume/bind-mount دائم في Docker.

### لماذا يهمّ هذا؟

الحاوية:

```text
يمكن إعادة بنائها/إنشاؤها
```

أما بيانات Jenkins:

```text
يجب أن تبقى
```

وهذا الفصل بينهما مفهوم أساسي في تشغيل حاويات Docker.

### مشكلة ملكية الملفات في Linux

يجب أن يكون مجلد المضيف قابلًا للكتابة من المستخدم الذي يشغّل Jenkins داخل الحاوية.

ويحل المصدر ذلك بإنشاء مجموعة مشتركة:

```text
jenkins_shared
```

وإضافة عدة مستخدمين:

```text
ec2-user    # المستخدمون المضافون
docker
jenkins
nginx
```

إلى تلك المجموعة.

ثم يغيّر الملكية والصلاحيات على:

```text
jenkins/var/jenkins_home    # مجلد Jenkins على المضيف
```

### تمرير UID/GID عبر `.env`

يكتب المصدر:

```text
JENKINS_UID=<معرّف مستخدم jenkins>
JENKINS_GID=<معرّف مجموعة jenkins>
```

في ملف `.env`.

ثم يستخدم Docker Compose:

والفكرة المهمة:

> تستخدم عملية الحاوية هوية مستخدم/مجموعة تطابق صلاحيات جهة المضيف التي يتوقعها مجلد Jenkins الدائم.

## المصطلحات الأساسية

| المصطلح | المعنى |
|---|---|
| Jenkins | خادم أتمتة يستخدمه المصدر في الـ deployment |
| Jenkins home | مجلد الحالة الدائمة لـ Jenkins |
| UID/GID | هويتان رقميتان لمستخدم/مجموعة في Linux |
| Bind mount | مجلد على المضيف يُحمَّل داخل حاوية |
| نواة Jupyter (Jupyter kernel) | بيئة Python التي تنفّذ خلايا الدفتر |
| Random Forest | خوارزمية تصنيف يستخدمها المصدر |
| تقسيم Train/test | الفصل بين بيانات التدريب وبيانات الـ evaluation |
| Precision | نسبة التنبؤات الموجبة التي كانت صحيحة |
| Recall | نسبة الحالات الموجبة الفعلية التي حُدّدت بشكل صحيح |
| Pickle | تسلسل (serialization) في Python يستخدمه المصدر لحفظ النموذج |
| الحمولة (Payload) | بيانات جسم الطلب |
| HTTP Basic Auth | أسلوب مصادقة تستخدمه Flask API في المصدر |
| الوكيل العكسي (Reverse proxy) | Nginx يوجّه الحركة الخارجية إلى الخدمات الداخلية |
