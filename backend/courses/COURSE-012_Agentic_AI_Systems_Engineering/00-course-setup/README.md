# COURSE-012 Setup

Complete this setup before starting the MCP-heavy implementation modules.

1. Clone or create your working repository.
2. Use Python 3.11+ in a dedicated virtual environment.
3. Install the dependencies required by your local implementation.
4. Keep provider/API credentials in a local `.env` or secret manager, never in source control.
5. Install Node.js 20+ if you will launch npm-distributed MCP servers with `npx`.
6. Verify `python`, `node`, `npm`, and `npx` point to the environments you expect.

The source appendices are treated as setup/reference material rather than curriculum lessons.
