## 1. ما معنى Segmentation؟



تُنتج Image classification Label واحدة للصورة كاملة.



وتُنتج Object detection مواقع تقريبية للكائنات مثل Bounding boxes.



أما Image segmentation فتقدم تفسيرًا أكثر كثافة:



```text
image — الصورة
  ↓
label / region assignment — إسناد Label أوRegion
for individual pixels — لكل Pixel على حدة
```



رسميًا، تقوم Segmentation بتقسيم Image domain إلى Regions:



```text
Omega = R1 ∪ R2 ∪ ... ∪ Rk — تقسيم مجال الصورة إلى Regions
```



بحيث ينبغي أن تكون كل Region ذات معنى وفقًا للمهمة.



وقد يعني "ذات معنى":



- Intensity متشابهة،

- Color/Texture متشابهة،

- Connected object region،

- Foreground مقابل Background،

- Semantic class واحدة،

- Instance منفردة،

- تمثيل Panoptic كامل للمشهد.



### التطور في هذا الفصل



يعرض Source chapter الـ Segmentation باعتبارها تطورًا:



```text
intensity rules — قواعد تعتمد على Intensity
    ↓
edges / morphology / topography — Edges وMorphology وTopography
    ↓
regions / graphs / energy minimization — Regions وGraphs وتقليل Energy
    ↓
handcrafted features + machine learning — Features مصممة يدويًا مع Machine learning
    ↓
CNN dense prediction — تنبؤ Dense باستخدام CNN
    ↓
transformer / query / universal segmentation — Transformer وQueries وUniversal segmentation
```

### ثلاثة أنماط حديثة للمخرجات



**Semantic segmentation**



يحصل كل Pixel على Class:



```text
road, sky, person, tree, ... — أمثلة لفئات Semantic مثل الطريق والسماء والشخص والشجرة
```



يمكن لشخصين مختلفين مشاركة Label نفسها وهي `person` دون التمييز بينهما.

```text

person #2 — الشخص الثاني

```



**Panoptic segmentation**



تجمع بين:



- **things** — Object instances قابلة للعد،

- **stuff** — Regions غير محددة ككائنات منفصلة مثل Sky أو Road.

## 2. Threshold-based segmentation و Multi-Otsu



تجمع Thresholding الـ Pixels وفق Intensity.



بالنسبة إلى Binary segmentation:



```text
pixel < T  -> class 0 — الـ Pixel تحت Threshold تُسند إلى Class صفر
pixel >= T -> class 1 — الـ Pixel عند Threshold أوفوقها تُسند إلى Class واحد
```



### مبدأ Otsu



تختار Otsu Threshold تزيد الفصل بين Classes إلى أقصى حد.



يصف Source ذلك باستخدام **Between-class variance**.



الفكرة المركزية:



> اختر Thresholds بحيث تكون Class means منفصلة قدر الإمكان عن Global intensity mean.



### Multi-Otsu متعددة العتبات



قد تحتوي الصور الحقيقية على أكثر من مجموعتي Intensity.



بالنسبة إلى `K` Classes، تختار Multi-Otsu:



```text
K - 1 thresholds — عدد Thresholds المطلوبة لعدد K من Classes
```



على سبيل المثال، تحتاج ثلاث Classes إلى Thresholds اثنتين:



```text
[0 ... t1]       -> class 0 — Range الأولى تُسند إلى Class صفر
(t1 ... t2]      -> class 1 — Range الوسطى تُسند إلى Class واحد
(t2 ... max]     -> class 2 — Range الأخيرة تُسند إلى Class اثنين
```

يقول الفصل إنها تعمل بصورة أفضل عندما:

- يكون Noise منخفضًا،

- تمتلك Classes ذات المعنى Intensities قابلة للفصل.

## 3. Watershed و Morphology وعدّ الكائنات

```text
dark regions -> valleys / basins — Regions الداكنة تُمثل Valleys أوBasins
bright regions -> mountains — Regions الساطعة تُمثل Mountains
gradient magnitude -> boundary terrain — Gradient magnitude تمثل Terrain الخاصة بالحدود
```

## 4. Superpixels: SLIC و MaskSLIC و RAG merging



تجمع Superpixels الـ Neighboring pixels داخل Regions صغيرة متماسكة Perceptually.



وعادةً تكون **Over-segmentation**:



```text
pixels — وحدات الصورة Pixel
  ↓
many small homogeneous regions — Regions صغيرة متجانسة كثيرة
  ↓
later grouping / reasoning — Grouping أوReasoning لاحقة
```



وهي ليست Semantic objects تلقائيًا.



### خوارزمية SLIC



تنفذ SLIC Localized clustering داخل Space مشتركة تحتوي:



- Spatial coordinates،

- Color components، غالبًا في Lab space.



تجمع Distance الخاصة بها بين:



```text
color similarity — تشابه اللون
+
spatial proximity — القرب المكاني
```



ويتحكم Compactness parameter في Trade-off.



### خوارزمية MaskSLIC



تقيّد MaskSLIC تكوين Superpixels داخل Region of interest مقدمة.



وقد يؤدي ذلك إلى:



- منع Superpixels غير المهمة في Background،

- تحسين الالتزام بـ Object boundaries.



### مخطط تجاور المناطق (Region Adjacency Graph — RAG)



غالبًا ما تُجزّئ Superpixels كائنًا واحدًا إلى Pieces كثيرة.



يمثل RAG:



```text
nodes -> regions — Nodes تمثل Regions
edges -> neighboring region relationships — Edges تمثل علاقات Regions المتجاورة
```



يمكن أن تتضمن Region features Mean color.



ويمكن Merge للـ Adjacent similar regions بصورة Hierarchical.



الـ Pipeline المفاهيمية:



```text
image — الصورة
  ↓ SLIC — مرور عبر SLIC
many superpixels — Superpixels كثيرة
  ↓ build adjacency graph — بناء Adjacency graph
region similarity weights — أوزان تشابه Regions
  ↓ hierarchical merging — تنفيذ Hierarchical merging
larger meaningful regions — Regions أكبر ذات معنى
```

## 5. Felzenszwalb و Quickshift و Watershed ودور Region grouping



يقارن Source عدة Region/Superpixel methods.



### تجزئة Felzenszwalb المعتمدة على Graph



نمذج الصورة كـ Graph:



```text
node -> pixel — Node تمثل Pixel
edge -> neighboring pixels — Edge تمثل Pixels متجاورة
weight -> appearance difference — Weight تمثل اختلاف المظهر
```



في البداية:



```text
each pixel = its own component — كل Pixel تبدأ كـ Component مستقلة
```



تُفحص Edges بترتيب متزايد من Dissimilarity.



تُدمج Components عندما:



- يكون Boundary difference صغيرًا بما يكفي،

- مقارنةً بـ Internal variation الخاصة بها.



يؤثر Scale parameter في Segmentation granularity.



### خوارزمية Quickshift



تعامل Quickshift الـ Pixels كـ Samples داخل Joint spatial-color space.



تقدّر Density وتربط Pixels نحو Nearby higher-density points.



وتنشأ Segments حول Density modes.



هذه فكرة Mode-seeking بدل Fixed-`K` clustering.



### خوارزمية Watershed



تجمع Watershed وفق Topographic flooding.



### خوارزمية SLIC



تركز SLIC على Superpixels منتظمة Compact ومتجانسة Color.



### المقارنة المهمة



تجمع هذه Algorithms الـ Regions لأسباب مختلفة:



```text
Felzenszwalb -> graph/component evidence — Felzenszwalb تعتمد على Evidence من Graph وComponents
Quickshift   -> density modes — Quickshift تعتمد على Density modes
Watershed    -> topographic basins — Watershed تعتمد على Topographic basins
SLIC         -> localized clustering — SLIC تعتمد على Localized clustering
```



بعد ذلك يطبق الفصل RAG merging على عدة Methods للانتقال من Initial regionization إلى Segments أكبر.

## 6. Variational segmentation: Chan–Vese و Mumford–Shah



تعرّف Variational methods **Energy** ثم تبحث عن Segmentation التي تقللها.



بنية عامة:



```text
energy = — تعريف Energy
data fidelity — مدى مطابقة Representation للبيانات
+
lambda * regularity — وزن Regularity
```



تكافئ Data term تفسير الصورة جيدًا.



وتمنع Regularization term الحدود غير المعقولة أوالمعقدة أكثر من اللازم.



### Active contours بأسلوب Chan–Vese



تعتمد Chan–Vese على Regions.



وبخلاف Gradient-based contours، تستطيع Segmentation لكائن حتى عندما تكون Boundary المرئية ضعيفة.



تشجع Energy الخاصة بها على:



- أن تشبه Pixels داخل Contour Inside mean،

- أن تشبه Pixels خارجها Outside mean،

- أن تظل Contour منتظمة بصورة معقولة.

### نموذج Mumford–Shah



تقوم Mumford–Shah بالـ Reasoning بصورة مشتركة حول:



- Piecewise-smooth approximation،

- Edges/Discontinuities،

- تعقيد الحدود (Boundary complexity).



توازن Energy مفاهيميًا بين:



```text
fit the observed image — ملاءمة الصورة الملحوظة
+
keep each region smooth — الحفاظ على Smoothness لكل Region
+
avoid unnecessary boundaries — تجنب Boundaries غير الضرورية
```



### تقريب Ambrosio–Tortorelli



يعد Direct Mumford–Shah minimization صعبًا.



يقدم الفصل Auxiliary edge variable بحيث يمكن Optimization للمشكلة بصورة تقريبية.



تتناوب Demonstration بين:



```text
solve edge indicator — حل Edge indicator
solve smooth image — حل Smooth image
repeat — كرر
```



وينتج ذلك:



- Representation ملساء/Segmented،

- خريطة الحواف (Edge map).

## 7. GrabCut و Conditional Random Fields



### خوارزمية GrabCut



تجمع GrabCut بين:



- Gaussian Mixture Models لمظهر Foreground/Background،

- Graph-cut optimization،

- Initialization يقدمها المستخدم.



عادةً يرسم المستخدم Rectangle حول Object.



تحصل Pixels على إحدى حالات عدة:



```text
sure background — Background مؤكدة
sure foreground — Foreground مؤكدة
probable background — Background محتملة
probable foreground — Foreground محتملة
```



### فهم Energy



توازن GrabCut بين:



```text
unary/data term — Unary أوData term
-> how well a pixel fits foreground/background appearance — مدى توافق Pixel مع مظهر Foreground أوBackground

pairwise/smoothness term — Pairwise أوSmoothness term
-> nearby similar pixels prefer consistent labels — Pixels المتقاربة والمتشابهة تفضّل Labels متسقة
```



يتم بناء Graph تحتوي:



- Pixel nodes،

- Source = Foreground،

- Sink = Background — الطرف الخاص بالخلفية.



تنتج Min-cut / Max-flow Globally optimized binary labeling.

### الحقول العشوائية الشرطية (Conditional Random Fields — CRFs)



تعمل CRFs على Refinement لتنبؤات Labels بصورة Probabilistic.



تجمع CRF energy أيضًا بين:



- Unary potential،

- Pairwise potential — حد العلاقة بين Labels.



تستخدم Dense CRF في الفصل Pairwise kernels مهمتين.



**Spatial Gaussian**



تشجع Nearby pixels على امتلاك Labels متشابهة.



**Bilateral**



تشجع Nearby pixels ذات Colors المتشابهة على مشاركة Labels مع الحفاظ على Color boundaries.



### تقريب Mean-field



تعد Exact dense CRF inference مكلفة.



تقرب Mean-field inference التوزيع باعتباره Product من Per-pixel label distributions وتعمل Iterative updates لها.



تقوم Iteration واحدة مفاهيميًا بما يلي:



```text
message passing — تمرير Messages
→ pairwise filtering — تنفيذ Pairwise filtering
→ compatibility transform — تنفيذ Compatibility transform
→ add unary evidence — إضافة Unary evidence
→ normalize — تطبيق Normalization
```



والنتيجة Boundary-refined segmentation.



### GrabCut مقابل CRF



```text
GrabCut — خوارزمية GrabCut
-> interactive foreground/background segmentation — استخراج Foreground وBackground بصورة تفاعلية
-> graph cut + appearance models — Graph cut مع Appearance models

CRF — نموذج CRF
-> probabilistic segmentation refinement — Refinement احتمالي للـ Segmentation
-> context-aware, edge-aware label smoothing — Smoothing للـ Labels واعٍ بالسياق والـ Edges
```

## 8. Trainable classical segmentation و Ensembles



لا يجب أن تكون Classical segmentation قائمة على Rules فقط.



يبني الفصل Bridge نحو Deep learning عبر Training لـ Classifier على Engineered pixel features.



### Pixel كـ Feature vector



لكل Pixel:



```text
features = — تعريف Features
[
    intensity, — قيمة Intensity
    multiscale texture, — Texture متعددة المقاييس
    derivative/Hessian-type information, — معلومات مشتقات من نوع Hessian
    ...
]
```



يستخدم الفصل Multiscale features محسوبة عبر عدة Gaussian scales.



تلتقط Small scales:



- Fine texture،

- تراكيب صغيرة (Small structures).



وتلتقط Large scales:



- Shape/Regions أوسع.



### Segmentation باستخدام Random Forest



يتم تقديم Sparse training labels يدويًا.



ثم:



```text
labeled pixels + handcrafted features — Pixels معلّمة مع Handcrafted features
        ↓
Random Forest training — Training لنموذج Random Forest
        ↓
predict class for every pixel — Predict لـ Class لكل Pixel
        ↓
segmentation map — خريطة Segmentation
```



باستخدام أدوات scikit-image، يتم Training للـ Classifier على Labeled locations فقط.

### تجميع نماذج Segmentation (Ensemble segmentation)



ترتكب Methods مختلفة أخطاء مختلفة.

**Soft voting**


## 9. Deep segmentation و Fully Convolutional Networks



يتعلم Deep learning:



```text
features + decision rule — Features مع Decision rule
```



معًا من Data.



وبدل Engineering يدوي لـ Intensity و Texture و Edge features، تتعلم Model تمثيلات Hierarchical بصورة End-to-end.



### دالة الهدف في التدريب (Training objective)



يصف الفصل Loss تقارن بين:



```text
predicted segmentation — Segmentation المتنبأ بها
vs. — مقابل
ground-truth mask — الـ Mask المرجعية الصحيحة
```



مع أمثلة مثل:



- Cross-entropy،

- Dice loss — خسارة Dice.



### الشبكات الالتفافية بالكامل (Fully Convolutional Networks — FCNs)



تضغط Classification CNN عادةً Features وتنتهي بـ Fully connected layers.



أما FCNs فتحذف Fully connected layers وتحافظ على Spatial feature maps.



مفاهيميًا:



```text
image — الصورة
  ↓ encoder — المرور عبر Encoder
deep feature map — خريطة Features عميقة
  ↓ class-score convolutions — Convolutions خاصة بـ Class scores
coarse semantic map — Semantic map تقريبية
  ↓ upsample — تنفيذ Upsampling
full-resolution segmentation — Segmentation بالدقة الكاملة
```



### وصلات التخطي (Skip connections)



تحتوي Deep features على Semantics قوية لكنها تفقد Spatial precision.



بينما تحتفظ Shallower features بتفاصيل أكثر.



تجمع FCN-style fusion بين:



```text
deep semantics — Semantics عميقة
+
shallow localization — Localization من Layers سطحية
```

## 10. DeepLab: Atrous convolution و ASPP و CNN ensembles

```text
x . x . x — مواقع Sampling مع فجوات
. . . . .
x . x . x — مواقع Sampling مع فجوات
. . . . .
x . x . x — مواقع Sampling مع فجوات
```

## 11. Instance segmentation: Mask R-CNN و YOLO-style segmentation



تجيب Semantic segmentation عن:



```text
which class does this pixel belong to? — إلى أي Class تنتمي هذه Pixel
```



أما Instance segmentation فتضيف سؤالًا آخر:




1. Backbone مثل ResNet + FPN،

2. Region Proposal Network،

   - Class prediction،

   - قناع instance ثنائي.

```text
classification loss — خسارة Classification
+
box regression loss — خسارة Box regression
+
mask loss — خسارة Mask
```



### آلية ROIAlign



تحتاج Pixel-accurate masks إلى Spatial alignment.



تستخدم ROIAlign Interpolation بدل Coarse quantized ROI pooling.



وهذا يقلل Alignment error بين Features و Object masks.

يشدد المصدر على:



- Accuracy قوية،

- Two-stage processing،

## 12. أسس Transformers للـ Segmentation



تمتلك CNNs Locality bias قوية.



أما Transformers فتمثل Long-range relationships صراحةً عبر Attention.



### من Image إلى Tokens



قسّم Image إلى Patches.



يصبح كل Patch Token:



```text
patch — Patch من الصورة
  ↓ flatten / projection — Flatten أوProjection
embedding vector — متجه Embedding
```



ثم اجمع جميع Token embeddings:



```text
image -> token sequence — تحويل Image إلى Token sequence
```



يشير الفصل إلى أن Patch projection يمكن أيضًا اعتبارها Convolution يكون فيها Kernel size و Stride مساويين لـ Patch size.



### المعلومات المكانية (Positional information)

تتعامل Architectures المختلفة مع Spatial information بطرق مختلفة.



تشمل أمثلة المصدر:



- Learnable positional embeddings في ViT/DPT،

- Relative positional bias في Swin،

- لا يوجد Explicit positional encoding في SegFormer.



### Q و K و V



لكل Token:



```text
Query  -> what am I looking for? — Query تمثل ما الذي أبحث عنه
Key    -> what do I contain? — Key تمثل ما الذي يحتويه Token
Value  -> what information do I provide? — Value تمثل المعلومات التي يقدمها Token
```



تقارن Scaled dot-product attention الـ Queries مع Keys وتستخدم Weights الناتجة لدمج Values.

- Geometry،

- Texture،

- Semantics — المعلومات الدلالية.



### كتلة Transformer (Transformer block)



تتضمن Transformer encoder layer:



- Normalization،

- Residual connection،

- Normalization ثانية،

- Feed-forward network،

- Residual connection ثانية.



### التحدي الحسابي

- Hierarchical representations،

- Efficient decoders،

## مفاهيم خاطئة مهمة



### المفهوم الخاطئ 1



> Segmentation و Classification هما الشيء نفسه لأن كلتيهما تُسند Labels.



### لماذا هذا خاطئ؟



تعيد Classification Image-level labels؛ بينما تعيد Segmentation Dense spatial labels أو Regions.



### المفهوم الخاطئ 2



> تكتشف Multi-Otsu Semantic classes.



### لماذا هذا خاطئ؟



هي تفصل Intensity distributions. ولا تضمن Semantic meaning.



### المفهوم الخاطئ 3



> تحل Watershed تلقائيًا مشكلة Touching-object segmentation دون إعداد.



### لماذا هذا خاطئ؟



قد تؤدي Noise و Poor markers إلى Over-segmentation شديد أو Region splitting غير صحيحة.



### المفهوم الخاطئ 4



> Superpixels هي Final semantic objects.



### لماذا هذا خاطئ؟



هي عادةً Low-level homogeneous regions يمكن استخدامها كـ Intermediate representation فعالة.



### المفهوم الخاطئ 5



> تتطلب Chan–Vese Strong visible edges.



### لماذا هذا خاطئ؟



هي Region-based ويمكنها العمل عندما تكون Boundaries ضعيفة إذا اختلفت إحصائيات Regions الداخلية والخارجية.



### المفهوم الخاطئ 6



> CRF refinement هي مجرد Ordinary image blurring.



### لماذا هذا خاطئ؟



تعمل Pairwise terms على Smooth للـ Labels بصورة Probabilistic ويمكنها الحفاظ على Boundaries باستخدام Bilateral appearance information.



### المفهوم الخاطئ 7



> لا تحتوي Random Forest segmentation pipeline على Learning لأن Features مصنوعة يدويًا.



### لماذا هذا خاطئ؟



Features Engineered، لكن Classifier ما تزال تتعلم Decision boundary من Labeled pixels.



### المفهوم الخاطئ 8



> تفصل Semantic segmentation كل شخص داخل Mask مختلفة.



### لماذا هذا خاطئ؟



تدمج Semantic segmentation Same-class pixels مفاهيميًا؛ أما Instance segmentation فتفصل Objects.



### المفهوم الخاطئ 9



> تزيد Atrous convolution Receptive field فقط عبر Downsampling للـ Feature maps.



### لماذا هذا خاطئ؟



هي توسع Sampling spacing داخل Convolution kernel مع الحفاظ على Spatial output أكثر كثافة.



### المفهوم الخاطئ 10



> تتحول RGB image إلى Transformer input ببساطة عبر اعتبار كل Pixel Token منفردًا في كل Architectures.



### لماذا هذا خاطئ؟



يصف Source Patch/Token embeddings؛ ثم تختلف Architectures في Hierarchy و Spatial representation.



### المفهوم الخاطئ 11



> تحل DETR و SegFormer و Mask2Former الـ Segmentation بالطريقة نفسها.



### لماذا هذا خاطئ؟



DETR Query/Object-centric، و SegFormer Hierarchical dense prediction، و Mask2Former تستخدم Mask classification.



### المفهوم الخاطئ 12



> Universal segmentation architecture تعني أن Training data لم تعد مهمة.



### لماذا هذا خاطئ؟



توضح أمثلة المصدر أن Datasets مثل ADE20K و Cityscapes تحدد Label spaces مختلفة و Scene knowledge مختلفة.
