## 1. التعلم من البيانات دون Labels

معظم بيانات العالم الحقيقي غير labeled.

قد يكون لديك:

```text
X = input features — الخصائص المدخلة
```

من دون:

```text
y = target labels — التسميات المستهدفة
```

وهذا ما يجعل **unsupervised learning** مفيدًا.

فبدلًا من تعلم mapping مباشر:

```text
X -> y
```

تحاول algorithm اكتشاف structure داخل:

```text
X
```

نفسها.

يركز الفصل على ثلاث مهام رئيسية.

### Clustering

تجميع instances المتشابهة معًا.

أمثلة:

- customer segmentation،
- تجميع documents أوimages المتشابهة،
- search وrecommendation،
- استكشاف data،
- feature engineering.

### Anomaly Detection

تعلم شكل data الطبيعية ثم التعرف على examples غير المعتادة.

أمثلة:

- fraud،
- المنتجات المعيبة،
- suspicious network activity،
- sensor readings غير المعتادة،
- إزالة outliers قبل model training.

تسمى الأمثلة الطبيعية غالبًا:

```text
inliers — النقاط العادية
```

أما الأمثلة غير المعتادة فتسمى:

```text
anomalies — الحالات الشاذة
أو
outliers — القيم المتطرفة
```

### Density Estimation

تقدير مدى كثافة توزيع data عبر feature space.

المناطق عالية الكثافة:

```text
كثير من المشاهدات المعقولة
```

أما المناطق منخفضة الكثافة:

```text
مشاهدات نادرة / غير معتادة
```

لذلك ترتبط density estimation طبيعيًا بـ anomaly detection.

### Classification مقابل Clustering

في classification توجد target labels معروفة.

أما clustering فلا تستخدم labels.

{{image:classification-vs-clustering}}

ليست cluster مفهومًا رياضيًا واحدًا يصلح لكل الحالات.

فالـ algorithms المختلفة تعرّف clusters بطرق مختلفة:

```text
k-means:
نقاط قريبة من مركز (centroid)

DBSCAN:
مناطق متصلة عالية الكثافة

Gaussian mixture:
نقاط يُرجَّح أنها تولدت من التوزيع الاحتمالي نفسه
```

لذلك تعتمد "أفضل" clustering algorithm على نوع structure الذي تتوقع وجوده في data.

## 3. كيف تتعلم k-means فعليًا؟

افترض أن centroids معروفة بالفعل.

عندها يصبح إسناد كل instance سهلًا:

```text
إسناد كل نقطة إلى أقرب centroid
```

والآن افترض أن cluster memberships معروفة.

عندها يصبح حساب كل centroid سهلًا:

```text
centroid = متوسط كل النقاط في ذلك العنقود
```

لكن في البداية لا نعرف أيًا منهما.

تحل k-means هذه المشكلة بالتناوب بين الخطوتين البسيطتين.

### خوارزمية k-means

1. اختر `k` initial centroids.
2. أسند كل instance إلى أقرب centroid.
3. أعد حساب كل centroid على أنه mean للـ instances المسندة إليها.
4. أعد إسناد جميع instances.
5. حدّث centroids من جديد.
6. كرر حتى تتوقف centroids عن الحركة.

{{image:kmeans-iterative-algorithm}}

تتحسن objective عند كل iteration لأن total squared distance إلى أقرب centroids لا يمكن أن تستمر في الزيادة.

وفي النهاية تصل algorithm إلى convergence.

### Convergence لا تضمن أفضل Solution

initial centroids مهمة.

يمكن لمواضع البداية العشوائية المختلفة أن تؤدي إلى clusters نهائية مختلفة.

{{image:kmeans-initialization-local-optima}}

## 4. اختيار عدد Clusters

تحتاج k-means إلى:

```text
k = عدد العناقيد
```

لكن datasets الحقيقية نادرًا ما تخبرك بالقيمة الصحيحة.

اختيار عدد قليل جدًا من clusters يدمج groups مختلفة.

واختيار عدد كبير جدًا يقسم groups ذات معنى إلى أجزاء أصغر.

### لماذا Minimum Inertia لا تكفي؟

مع زيادة `k`:

```text
يزداد عدد المراكز
تقترب النقاط من مركز ما
تنخفض inertia
```

لذلك، إذا اخترت `k` التي تعطي أقل inertia فقط، فستندفع إلى استخدام clusters أكثر فأكثر.

وهذا لا يحل المشكلة.

### Elbow Method

ارسم:

```text
k
مقابل
inertia
```

غالبًا تنخفض curve بسرعة في البداية، ثم تبدأ في التسطح.

تبدو نقطة الانتقال مثل elbow.

{{image:kmeans-elbow-method}}

تكون elbow candidate معقولة لقيمة `k`.

لكن تحديدها قد يكون subjective.

### Silhouette Coefficient

metric أكثر إفادة هي **silhouette coefficient**.

لكل instance:

```text
a = متوسط المسافة إلى أمثلة عنقوده نفسه
b = متوسط المسافة إلى أمثلة أقرب عنقود آخر
```

ثم:

```text
silhouette = (b - a) / max(a, b) — معامل silhouette
```

التفسير:

```text
قريب من +1
-> داخل عنقوده بوضوح

قريب من 0
-> قرب حدود عنقود

قريب من -1
-> ربما أُسند إلى عنقود خاطئ
```

لحساب mean score:

### Silhouette Diagrams

ما زالت mean score واحدة تخفي مشكلات خاصة بكل cluster.

تعرض silhouette diagram توزيع silhouette coefficients لكل cluster.

{{image:silhouette-diagram-cluster-selection}}

يمكن أن تكشف هذه diagrams:

- clusters ذات separation ضعيف،
- عدم توازن cluster sizes،
- عددًا كبيرًا من borderline points،
- قيمة `k` جيدة إحصائيًا لكنها غير مناسبة عمليًا.

### لا توجد Metric تلغي Domain Meaning

ينبغي أن تكون cluster مفيدة للـ task.

في customer segmentation مثلًا:

```text
k = 20
```

قد تعطي mathematical score أفضل قليلًا، لكنها قد تنتج segments أكثر مما يستطيع marketing team التعامل معه.

لذلك اجمع دائمًا بين metrics ومتطلبات use case.

## 5. حدود k-means وتطبيقاتها العملية

تتميز k-means بأنها:

- سريعة،
- scalable،
- بسيطة،
- فعالة مع compact centroid-shaped clusters.

لكن لديها assumptions.

### أين تواجه k-means صعوبة؟

قد تعمل k-means بصورة سيئة عندما تكون clusters:

- مختلفة الأحجام،
- مختلفة الكثافات،
- elongated،
- curved أوirregular.

```text

```

فقد تهيمن feature كبيرة scale على Euclidean distance.


بدلًا من اختيار examples عشوائية للـ manual labeling، يمكنك اختيار examples ممثلة للبيانات.

### تسمية الأمثلة الممثِّلة: Label Representative Instances

يقوم الفصل بعمل clustering لـ digits dataset إلى 50 clusters.

⟦CODE_10⟧

كل image مختارة هي training instance الأقرب إلى إحدى centroids.

{{image:cluster-representative-labeling}}

توضح نتيجة المصدر القيمة العملية:

```text
50 مثالًا مصنّفًا اختيرت عشوائيًا
```

ميزانية labeling نفسها.

لكن اختيار labels أفضل.

### Label Propagation

بعد manually labeling للـ representative instance في كل cluster، يمكن نشر ذلك label إلى بقية instances في cluster نفسها.

مفاهيميًا:

```text
مثال مركز العنقود مصنَّف بـ "7"
        |
نشر التسمية
        |
الأعضاء القريبون يحصلون أيضًا على "7"
```

ينشئ ذلك عددًا أكبر بكثير من pseudo-labeled examples.

ويذكر المصدر زيادة أخرى في accuracy.

### النشر الجزئي للتسميات: Partial Label Propagation

لا تثق في كل member داخل cluster بصورة عمياء.

قد تكون instances البعيدة عن centroid:

- borderline cases،
- outliers،
- غير ممثلة جيدًا بواسطة cluster.

إحدى الاستراتيجيات هي نشر labels فقط إلى النسبة الأقرب من instances.

يحتفظ المصدر بأقرب 50% داخل كل cluster ويحقق performance أفضل.

### Active Learning

تأخذ **active learning** الفكرة خطوة أبعد.

بدلًا من أن يقوم البشر بعمل labels لأمثلة عشوائية، يطلب Model labels لأمثلة informative بدرجة خاصة.

استراتيجية شائعة هي **uncertainty sampling**:

1. درّب Model على instances labeled حاليًا،
2. نفذ prediction على instances غير labeled،
3. ابحث عن examples التي يكون Model أقل ثقة فيها،
4. اطلب من expert وضع labels لها،
5. أعد training،
6. كرر حتى لا يعود labeling الإضافي مستحقًا للتكلفة.

يركز ذلك الجهد البشري حيث تكون labels أكثر قيمة.

## 7. DBSCAN: اكتشاف Clusters باستخدام Density

تعرّف k-means الـ clusters حول centroids.

أما **DBSCAN** فتستخدم approach مختلفًا تمامًا:

> Cluster هي منطقة متصلة ذات local density مرتفعة.

تستخدم DBSCAN hyperparameters أساسيين:

```text
eps — نصف قطر الجوار
min_samples — أقل عدد من العينات في الجوار
```

### Epsilon Neighborhood

لكل instance، انظر إلى جميع points الواقعة داخل مسافة:

```text
eps — نصف قطر الجوار
```

تسمى هذه المنطقة **epsilon neighborhood** للـ instance.

### Core Instance

تكون instance **core instance** إذا احتوت epsilon neighborhood الخاصة بها على ما لا يقل عن:

```text
min_samples
```

من instances، بما في ذلك نفسها.

تمثل core instances مناطق كثيفة.

### توسيع المناطق الكثيفة المتصلة

إذا كانت core instance قريبة من core instance أخرى، فإنهما تصبحان جزءًا من cluster نفسها.

يمكن لسلاسل طويلة من core points المتصلة أن تنشئ:

- curved clusters،
- irregular clusters،
- العناقيد التي لا تتخذ شكلًا حول مركز (non-centroid-shaped clusters).

### Anomalies

إذا كانت instance:

```text
ليس مثالًا جوهريًا (core instance)
و
ليس قريبًا بما يكفي من مثال جوهري
```

فتُصنف كـ anomaly.

في Scikit-Learn تحصل anomalies على:

```text
-1
```

### مثال

⟦CODE_11⟧

{{image:dbscan-eps-comparison}}

### لماذا DBSCAN قوية؟

يمكنها اكتشاف:

- cluster shapes عشوائية،
- عدد clusters تلقائيًا،
- anomalies بصورة طبيعية.

وعلى عكس k-means، لا تحتاج إلى:

```text
k
```

مسبقًا.

### أين تواجه DBSCAN صعوبة؟

تواجه DBSCAN مشكلات عندما:

- تختلف cluster densities اختلافًا كبيرًا،
- تكون low-density gaps بين clusters ضعيفة،
- تكون dataset ضخمة جدًا.

كما يعتمد أداؤها بشدة على اختيار قيم مناسبة لـ:

```text

و
min_samples
```

### Predicting لـ Instances جديدة

لا توفر `DBSCAN` في Scikit-Learn method قياسية باسم `predict()`.

حل عملي هو تدريب classifier آخر مثل k-NN باستخدام learned core instances.

وهذا يوضح تمييزًا مهمًا:

> Clustering للـ training data وإسناد future data ليستا دائمًا task algorithmic واحدة.

### الفكرة العامة لـ Expectation-Maximization

يتم fit للـ Gaussian mixtures باستخدام **expectation-maximization (EM)**.

وهي تتناوب بين خطوتين.

#### Expectation Step

تقدّر:

```text
ما مدى احتمال أن ينتمي كل مثال
إلى كل مكوّن Gaussian؟
```

وغالبًا تسمى هذه probabilities **responsibilities**.

#### Maximization Step

تُحدّث كل component باستخدام data، مع weighting وفق هذه responsibilities.

ثم تكرر.

يشبه ذلك k-means:

```text
k-means:
إسناد النقاط
تحديث المراكز

EM:
تقدير عضويات ناعمة (soft memberships)
تحديث معاملات التوزيع
```

لكن EM تتعلم أكثر بكثير:

- means،
- covariance،
- mixture weights.

⟦CODE_18⟧

### اختيار Threshold ينشئ Trade-Off

ارفع anomaly threshold:

```text
تمييز نقاط أكثر
-> اكتشاف anomalies حقيقية أكثر
-> إنتاج false positives أكثر
```

اخفض threshold:

```text
تمييز نقاط أقل
-> إنذارات كاذبة أقل
-> خطر تفويت anomalies أكثر
```

يرتبط هذا مباشرةً بـ precision/recall trade-off في classification.

### Anomaly Detection مقابل Novelty Detection

المصطلحان مرتبطان لكنهما ليسا متطابقين.

**Anomaly detection**

قد تحتوي training data بالفعل على outliers.

الهدف:

```text
إيجاد أمثلة غير معتادة
داخل بيانات قد تكون ملوَّثة
```

**Novelty detection**

يُفترض أن training data نظيفة.

الهدف:

```text
اكتشاف أمثلة مستقبلية
لا تشبه البيانات المعروفة بأنها طبيعية
```

هذا الفرق مهم لأن contamination أثناء training يمكن أن يغير definition الخاصة بما هو "طبيعي".

### طرق بديلة

يقدم الفصل أيضًا عدة بدائل.

**Isolation Forest**

تقسم feature space عشوائيًا.

تميل anomalies إلى أن تصبح isolated بعد عدد أقل من splits مقارنة بالـ points العادية.

مفيدة في high-dimensional outlier detection.

**عامل القيم الشاذة المحلي: Local Outlier Factor (LOF)**

تقارن local density حول point بكثافة neighbors المحيطين بها.

قد تكون point anomaly إذا كانت أكثر عزلة بكثير من nearby points.

**One-Class SVM**

تتعلم region تحتوي normal training examples.

مفيدة خصوصًا في novelty detection، لكنها لا تتوسع جيدًا إلى datasets ضخمة جدًا.

**Robust Covariance / EllipticEnvelope**

تلائم Gaussian-like envelope بطريقة robust مع تقليل تأثير outliers.

مفيدة عندما تتبع normal data تقريبًا Gaussian distribution واحدة.

**طرق خطأ إعادة البناء: Reconstruction-Error Methods**

يمكن لـ dimensionality-reduction models إعادة بناء normal examples جيدًا.

وغالبًا تكون reconstruction error للـ anomalies أكبر بكثير.

## 10. اختيار عدد Gaussian Components

مثل k-means، تحتاج Gaussian mixture القياسية إلى:

```text
n_components
```

لكن inertia وsilhouette score أقل موثوقية مع GMMs عندما تكون clusters:

- غير كروية،
- مختلفة الحجم،
- متداخلة.

بدلًا من ذلك، استخدم model-selection criteria.

### AIC وBIC

معياران شائعان هما:

- **معيار المعلومات: Akaike Information Criterion (AIC)**
- **معيار المعلومات: Bayesian Information Criterion (BIC)**

كلاهما يوازن:

```text
جودة الملاءمة (goodness of fit)
مقابل
تعقيد النموذج
```

قد يلائم Model التي تحتوي Gaussian components أكثر training data بصورة أفضل.

لكنها تمتلك parameters أكثر أيضًا.

عادةً تعاقب BIC model complexity بدرجة أقوى من AIC، خصوصًا مع زيادة dataset size.


استراتيجية أخرى:

⟦CODE_20⟧

اختر upper bound أكبر بصورة معقولة من العدد الحقيقي المتوقع للـ clusters.

وهذا يسمح للعدد الفعلي للـ clusters بأن يظهر أثناء fitting.

### لكن GMMs لديها Assumptions أيضًا

تعمل Gaussian mixtures بصورة جيدة خصوصًا مع:

```text
عناقيد إهليلجية شبيهة بـ Gaussian
```

لكنها ليست مثالية لكل geometry.

مع structures منحنية بشدة مثل moon-shaped clusters، قد تكون density-connected algorithm مثل DBSCAN أنسب بكثير.

## 11. دليل عملي للاختيار

يصبح اختيار techniques في هذا الفصل أسهل عندما ننظمها حسب assumptions.

| الطريقة | الفكرة الرئيسية | قوية عندما | ضعيفة عندما |
|---|---|---|---|
| k-means | nearest centroid | clusters compact وتقريبًا spherical؛ datasets كبيرة | shapes غير منتظمة، وكثافات/أحجام مختلفة |
| MiniBatchKMeans | k-means تقريبية باستخدام mini-batches | datasets ضخمة جدًا | solutions أقل دقة قليلًا |
| DBSCAN | مناطق كثيفة متصلة | arbitrary shapes وanomaly identification | كثافات مختلفة بقوة وlarge-scale computation |
| Gaussian mixture | مكوّنات Gaussian احتمالية | clusters ellipsoidal متداخلة وdensity estimation | geometry بعيدة بشدة عن Gaussian |
| Isolation Forest | عزل rare points بسرعة | كشف anomalies في البيانات عالية الأبعاد | ليست clustering method |
| LOF | مقارنة local densities | anomalies الكثافة المحلية | قد تكون مكلفة وحساسة للـ neighborhoods |
| One-Class SVM | تعلم boundary حول normal data | novelty detection وhigh-dimensional data | ضعيفة في التوسع إلى datasets كبيرة |

### اطرح هذه الأسئلة

عند اختيار unsupervised method:

```text
هل أعرف عدد العناقيد؟
هل العناقيد على شكل مراكز (centroid-like)؟
هل العناقيد متصلة بالكثافة؟
هل تتداخل أشكال العناقيد؟
هل أحتاج إلى احتمالات؟
هل أحتاج إلى درجات anomaly؟
هل تتسع الذاكرة للـ Dataset؟
هل سأحتاج إلى إسناد أمثلة مستقبلية؟
```

الإجابات توجهك عادةً نحو family مناسبة من algorithms.

## مفاهيم خاطئة مهمة (Important Misconceptions)

### المفهوم الخاطئ 1

> Cluster label هي نفسها Class label.

### لماذا هذا خطأ؟

Class labels هي targets معروفة تُقدم أثناء supervised learning. أما cluster IDs فتكتشفها unsupervised algorithm، ولا تملك semantic meaning جوهريًا حتى يفسرها إنسان.

### المفهوم الخاطئ 2

> k-means تجد دائمًا Solution الصحيحة بمجرد الوصول إلى Convergence.

### لماذا هذا خطأ؟

قد تصل k-means إلى local solution سيئة حسب centroid initialization.

### المفهوم الخاطئ 3

> Clustering ذات Inertia الأقل تملك دائمًا أفضل عدد من Clusters.

### لماذا هذا خطأ؟

تنخفض inertia عادةً مع زيادة `k`. استخدم elbow method وsilhouette analysis وdomain usefulness بدلًا من تقليل inertia بصورة عمياء.

### المفهوم الخاطئ 4

> تستطيع k-means نمذجة أي شكل للـ Clusters إذا أضفت عددًا كافيًا منها.

### لماذا هذا خطأ؟

تعتمد k-means أساسًا على nearest-centroid geometry، ولذلك لا تناسب كثيرًا من cluster shapes غير المنتظمة أوالمختلفة في scale.

### المفهوم الخاطئ 5

> تحتاج DBSCAN إلى معرفة عدد Clusters مسبقًا.

### لماذا هذا خطأ؟

تكتشف DBSCAN المناطق الكثيفة المتصلة من `eps` و`min_samples`، ويظهر عدد clusters من data نفسها.

### المفهوم الخاطئ 6

> تنفذ Gaussian Mixtures Hard Clustering تمامًا مثل k-means.

### لماذا هذا خطأ؟

تنتج GMM بصورة طبيعية membership probabilities، ولذلك تدعم soft probabilistic cluster assignments.

### المفهوم الخاطئ 7

> Anomaly Detection وNovelty Detection متطابقتان.

### لماذا هذا خطأ؟

تفترض novelty detection أن training data نظيفة، بينما يمكن تدريب anomaly detection على data تحتوي بالفعل على بعض outliers.

## المصطلحات الأساسية (Key Terminology)

| المصطلح | المعنى |
|---|---|
| Unsupervised learning | تعلم structure من data دون target labels |
| Clustering | تجميع instances المتشابهة |
| Cluster | مجموعة instances تعتبر متشابهة وفق تعريف algorithm |
| Centroid | mean location تمثل k-means cluster |
| Hard clustering | إسناد كل instance إلى cluster واحدة |
| Soft clustering | تمثيل درجات membership أوaffinity لعدة clusters |
| Inertia | مجموع squared distances من instances إلى أقرب k-means centroids |
| k-means++ | centroid initialization أذكى تنشر starting centroids بعيدًا عن بعضها |
| نسخة Mini-batch k-means | نسخة scalable من k-means تحدّث باستخدام mini-batches |
| Elbow method | اختيار k من النقطة التي يبدأ عندها تحسن inertia في التسطح |
| Silhouette coefficient | cluster-quality score تقارن within-cluster distance بأقرب cluster أخرى |
| Label propagation | تمديد labels من representative labeled instances إلى unlabeled instances مشابهة |
| Active learning | labeling تكراري يطلب فيه Model labels الأكثر إفادة |
| DBSCAN | density-based clustering algorithm تكتشف مناطق كثيفة متصلة |
| Epsilon neighborhood | المنطقة داخل مسافة `eps` من instance في DBSCAN |
| Core instance | instance في DBSCAN تحتوي epsilon neighborhood الخاصة بها على `min_samples` points على الأقل |
| Gaussian mixture model، أي نموذج الخليط الغاوسي | probabilistic model تمثل data كمزيج من Gaussian components |
| EM | Expectation-maximization algorithm المستخدمة في fitting لنماذج probabilistic ذات latent variables |
| Responsibility | estimated probability أن Gaussian component معينة ولدت instance |
| Density estimation | تقدير مدى احتمالية مناطق feature space المختلفة |
| Anomaly | instance غير معتادة أوذات density منخفضة |
| Novelty detection | اكتشاف examples جديدة لا تشبه clean normal training data |
| AIC | Information criterion توازن likelihood مع model complexity |
| BIC | Information criterion شبيهة بـ AIC وتعاقب complexity عادةً بقوة أكبر |
| Isolation Forest | anomaly detector يعتمد على سرعة عزل instances عبر random partitions |
| Local Outlier Factor، أي عامل القيم الشاذة المحلي | anomaly method تقارن local density بكثافة neighbors |
