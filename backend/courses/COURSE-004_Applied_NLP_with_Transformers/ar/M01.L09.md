## 2. عقلية Scaling و"الدرس المر"

يفتتح الفصل بحجة Richard Sutton القائلة إن General Methods القادرة على الاستفادة الفعالة من المزيد من Compute تتفوق غالبًا على الأنظمة التي تعتمد بدرجة كبيرة على Hand-designed Human Knowledge.

يربط الفصل هذه الفكرة بـ Transformers.

كانت أجيال BERT وGPT المبكرة تضيف كثيرًا من Architectural أو Objective Changes. لكن المصدر يلاحظ أن بعض أقوى Models في تلك الفترة كانت ببساطة إصدارات ضخمة جدًا من Transformer Designs بسيطة نسبيًا.

الدرس الأوسع ليس:

> Architecture لم تعد مهمة.

بل هو:

> **الأساليب العامة التي تستمر في التحسن كلما زادت Compute وData قد تكون شديدة القوة.**

يشير الفصل إلى أن Parameter Counts الخاصة بالـ Models ارتفعت بعدة Orders of Magnitude خلال بضع سنوات فقط من ظهور Transformer الأصلية.

## 3. Scaling Laws: الأداء يتغير بطريقة يمكن التنبؤ بها مع Scale

تدرس Scaling Laws كيف تتغير Language-model Loss عندما نغيّر ثلاث كميات رئيسية:

- N — Model Size / عدد Parameters،
- D — Dataset Size،
- C — Compute Budget.

يصف الفصل علاقات Empirical تتبع فيها Test Loss نمط Power Law سلسًا مع زيادة هذه الكميات.

على Log-log Plot، تبدو Power Law تقريبًا كخط مستقيم.

وهذا مهم لأن Small Cheap Experiment قد تساعد أحيانًا في تقدير سلوك Training Run أكبر بكثير.

### الاستنتاجات الرئيسية في الفصل

#### وسّع Model وData وCompute معًا

زيادة بُعد واحد فقط قد تؤدي إلى Diminishing Returns. لذلك يدافع الفصل عن Coordinated Scaling للـ Model Capacity وTraining Data وCompute.

#### Models الأكبر قد تكون أكثر Sample-efficient

قد تصل Model أكبر إلى مستوى Performance معين في عدد Training Steps أقل من Model أصغر.

#### Trends المبكرة قد تكون مفيدة

نعومة Scaling Curves تجعل Extrapolation ممكنة، على الأقل بصورة تقريبية.

[[IMAGE_NEEDED: Scaling laws on log-log axes | Three small charts showing test loss decreasing smoothly as compute, dataset size, and model size increase, with approximately straight trends on log-log axes | Learner should notice the similar power-law shape across N, D, and C]]

## 4. Scaling ليست مجرد "أضف Layers أكثر"

Large-model Scaling يخلق مشكلات هندسية وتنظيمية لا تظهر في Small Experiments.

يسلط الفصل الضوء على خمسة تحديات رئيسية.

### Infrastructure

التدريب على مئات أوآلاف Accelerators يحتاج إلى Distributed Systems وFast Communication وCareful Orchestration ومهارات هندسية متخصصة.

### Cost

قد تكلف Large Training Runs ملايين الدولارات. وهكذا يصبح Experiment Design مشكلة Resource Planning بقدر ما هو Modeling Problem.

### Dataset Curation

يصعب تنظيف Huge Datasets ومراجعتها. وتشمل المشكلات:

- Low-quality Text،
- Social Bias،
- Licensing Constraints،
- Personal Information،
- Expensive Preprocessing.

### Model Evaluation

يجب اختبار Large Model على Downstream Capability وBias وToxicity وأشكال السلوك غير المرغوب فيها. وحتى Evaluation نفسها قد تصبح مكلفة.

### Deployment

تشغيل Model تشغل عشرات أو مئات Gigabytes يخلق مشكلات Memory وLatency وInfrastructure حتى بعد انتهاء التدريب.

وهذا يعيدنا إلى Production Optimization Methods التي درسناها سابقًا: Distillation وQuantization وPruning وOptimized Inference Runtimes.

## 5. لماذا تصبح Self-attention عنق زجاجة مع Long Sequences؟

تقارن Standard Self-attention مواضع Tokens على هيئة أزواج.

لـ Sequence طولها n، تتعامل الـ Model مفاهيميًا مع Attention Matrix بحجم `n × n`.

لذلك إذا تضاعف Sequence Length:

```text
n      → n² مقارنة (Comparisons)
2n     → 4n² مقارنة (Comparisons)
```

هذا Quadratic Behavior يجعل Long Documents وSpeech وVideo وHigh-resolution Visual Inputs مكلفة.

تحاول Efficient-attention Research تجنب حساب كل Query-Key Pair ممكنة.

[[IMAGE_NEEDED: Quadratic self-attention growth | Attention matrices for short, medium, and long sequences shown growing from small square to much larger square, with n² highlighted | Learner should notice that doubling sequence length roughly quadruples the pairwise attention-score space]]

## 6. Sparse Attention: لا تقارن كل Token بكل Token

إحدى طرق تقليل Attention Cost هي حساب مجموعة فرعية فقط من Query-Key Pairs.

يصف الفصل عدة Reusable Sparsity Patterns.

### Global Attention

يمكن لعدد قليل من Special Tokens أن يحضر جميع Tokens الأخرى.

### Band Attention

تركز كل Token في الأساس على المواضع القريبة، ما ينتج Diagonal Band.

### Dilated Attention

تحضر Token إلى مواضع متباعدة بانتظام، مع تخطي بعض Intermediate Tokens.

### Random Attention

تحضر كل Query أيضًا إلى Selected Set من Random Positions.

### الانتباه المحلي داخل الكتل (Block-local Attention)

يتم تقسيم الـ Sequence إلى Blocks، وتتركز Attention داخل كل Block.

[[IMAGE_NEEDED: Atomic sparse attention patterns | Five small attention matrices showing global, band, dilated, random, and block-local patterns using filled cells for calculated scores and blank cells for skipped scores | Learner should compare how each pattern reduces the number of pairwise calculations]]

---

## 7. دمج Sparse Patterns: Longformer وBigBird

Sparse-attention Models العملية غالبًا ما تجمع عدة Atomic Patterns.

يعرض الفصل مثالين:

### Longformer

تجمع Local/Band Attention مع Selected Global-attention Positions.

### BigBird

تجمع Local Attention وGlobal Attention وRandom Attention.

تسمح هذه Sparse Patterns للـ Models التي يصفها المصدر بمعالجة Sequences تصل إلى 4,096 Token، أي أطول كثيرًا من BERT Limit المعتادة البالغة 512 Token.

يذكر الفصل أيضًا Data-driven Sparsity، حيث تحدد العلاقات بين Tokens أي Positions ينبغي أن تتفاعل. على سبيل المثال، تستخدم Reformer Hashing لتجميع Similar Tokens.

[[IMAGE_NEEDED: Longformer and BigBird compound sparsity | Two attention matrices side by side: Longformer showing local band plus global rows/columns, and BigBird adding random sparse links | Learner should notice that practical efficient-attention models combine multiple sparsity patterns]]

## 8. Linearized Attention: غيّر ترتيب العمليات

تحتفظ Sparse Attention بفكرة Attention نفسها، لكنها تزيل عددًا كبيرًا من Pairwise Comparisons.

أما Linearized Attention فتسلك طريقًا مختلفًا: تعيد تنظيم Similarity Computation بحيث لا نحتاج إلى بناء `n × n` Matrix المكلفة بالطريقة نفسها.

يصف الفصل Kernel-based Decompositions تسمح بإعادة ترتيب أجزاء من Attention Calculation وحسابها بكفاءة أكبر.

لا تحتاج إلى حفظ الاشتقاق الرياضي. احتفظ بالحدس:

```text
Standard Attention:
ابنِ Pairwise Token Interactions أولًا

Linearized Attention:
أعد ترتيب/تفكيك العمليات لتجنب Explicit Quadratic Work
```

يذكر الفصل Models مثل Linear Transformer وPerformer كأمثلة.

[[IMAGE_NEEDED: Standard versus linearized attention | A side-by-side computational diagram: standard attention explicitly forms a QK^T matrix, while linearized attention applies feature maps and rearranged matrix products without materializing the full pairwise matrix | Learner should focus on the structural difference rather than the detailed algebra]]

## 9. لماذا نتجاوز Text؟

Text قوية، لكنها تمثل العالم بصورة غير كاملة.

يسلط الفصل الضوء على عدة قيود للتعلم من Text فقط.

### انحياز الإبلاغ البشري (Human Reporting Bias)

ما يكتبه البشر لا يتناسب دائمًا مع ما يحدث فعلًا في الواقع.

### Common Sense

كثير من الحقائق اليومية نادرًا ما تُكتب لأن البشر يفترضون أنها معروفة ضمنيًا.

### Facts

Probabilistic Language Model قد تنتج Statements خاطئة، وليست Factual Database موثوقة بمفردها.

### Modality

Text-only Models لا تستطيع إدراك Audio أو Images أو Layouts أو Structured Tables مباشرة.

تحاول Multimodal Models ربط Language بمصادر أخرى للمعلومات.

## 10. تعامل مع Images كـ Sequences: iGPT

إحدى الطرق المبكرة لتمديد أفكار Transformer إلى Vision هي معاملة Image كسلسلة من Pixel Values.

تطبق iGPT Objective شبيهة بـ GPT بطريقة Autoregressive:

```text
القيم السابقة للبكسلات (Previous Pixel Values)
       ↓
التنبؤ بقيمة البكسل التالي (Predict the Next Pixel Value)
```

بعد Large-scale Image Pretraining، تستطيع الـ Model إكمال Partial Images، كما يمكن لRepresentations الخاصة بها دعم Classification.

الفكرة الأكبر مهمة:

> Transformer Architecture ليست مقيدة جوهريًا بـ Word Tokens؛ يمكن أيضًا تمثيل أنواع أخرى من البيانات كسلاسل.

## 11. Vision Transformer: حوّل Image Patches إلى Tokens

تتبع Vision Transformer (ViT) فكرة أقرب إلى BERT من فكرة GPT Pixel-by-pixel.

الـ Pipeline هي:

```text
Image
  ↓ تقسيم إلى Fixed-size Patches
Patches
  ↓ Linear Projection
Patch Embeddings
  + Position Embeddings
  ↓
Transformer Encoder
```

تلعب Image Patch دورًا مشابهًا لـ Token في NLP.

[[IMAGE_NEEDED: Vision Transformer patch pipeline | An image divided into equal square patches, each patch converted to an embedding, position embeddings added, then all patch tokens entering a transformer encoder | Learner should notice the analogy between image patches and text tokens]]

يذكر الفصل أن ViT تصبح قوية بصورة خاصة عندما يتم Pretraining لها على Image Datasets أكبر.

ويظهر أيضًا أن استخدام Image-classification Pipeline يبدو مشابهًا لـ NLP Pipelines التي استخدمناها سابقًا.

### امتداد إلى Video

تضيف Video بُعد الزمن إلى Vision. ويذكر الفصل TimeSformer، التي تستخدم Spatial وTemporal Attention Mechanisms منفصلة.

## 13. Speech-to-text باستخدام wav2vec 2.0

يمكن لـ Transformers معالجة Audio أيضًا.

يقدم الفصل wav2vec 2.0، التي تجمع Convolutional Processing مع Transformer Layers من أجل Automatic Speech Recognition (ASR).

الفكرة المهمة هي Self-supervised Pretraining على Unlabeled Audio.

هذا قد يقلل كمية Transcribed Speech المطلوبة لـ Downstream Training.

Pipeline عالية المستوى:

```text
الموجة الصوتية (Audio Waveform)
   ↓
استخراج الخصائص (Feature Extraction)
   ↓
تعلّم تمثيلات Transformer (Transformer Representation Learning)
   ↓
النسخ الكتابي للكلام (Speech Transcription)
```

[[IMAGE_NEEDED: wav2vec 2.0 speech-recognition pipeline | An audio waveform entering convolutional feature extraction, then transformer context layers, then producing a text transcription | Learner should notice the combination of low-level audio feature processing and transformer-based contextual representation learning]]

بعد ذلك يذكر الفصل wav2vec-U، التي تستكشف Speech Recognition باستخدام Unlabeled Speech وUnlabeled Text من دون الحاجة إلى Aligned Speech-text Pairs.

## 14. Multimodal Transformers تجمع عدة مصادر للمعلومات

Multimodal Model تعالج أكثر من نوع Input في الوقت نفسه.

يسلط الفصل الضوء على عدة تركيبات مهمة.

### Vision + Language لـ Question Answering

Models مثل LXMERT وVisualBERT تجمع Image Features مع Natural-language Questions للتنبؤ بالإجابات.

### Text + Image + Layout لفهم Documents

تستهدف LayoutLM Scanned Business Documents مثل Receipts وInvoices وForms.

وتستخدم عدة مصادر للمعلومات:

- Text،
- Visual Features،
- إحداثيات المكان والتخطيط (Spatial/Layout Coordinates).

هذا مهم لأن معنى Document يعتمد غالبًا على مكان ظهور المعلومة على الصفحة، لا على الكلمات وحدها.

## 15. Text-to-image Generation باستخدام DALL-E

يعرض الفصل DALL-E باعتبارها Generative Vision-language Model.

فكرتها العامة هي تمثيل Language وImage Information كـ Tokens داخل Autoregressive Modeling Framework واحدة.

```text
رموز النص الموجِّه (Text Prompt Tokens)
      +
رموز تمثيل الصورة (Image Representation Tokens)
      ↓
Transformer انحداري ذاتي (Autoregressive Transformer)
      ↓
الصورة المولَّدة (Generated Image)
```

التحول المفاهيمي مهم: الفكرة نفسها التي تتنبأ بـ Next Text Tokens يمكن تمديدها لتوليد Visual Content.

## 16. CLIP: محاذاة Image وText Embeddings

تستخدم CLIP Multimodal Objective مختلفة.

لديها:

- Image Encoder،
- Text Encoder.

كلاهما ينتج Embeddings في Shared Space.

أثناء التدريب، يتم تقريب Matching Image-caption Pairs من بعضها، بينما يتم إبعاد Mismatched Pairs.

هذا هو Contrastive Learning.

```text
الصورة (Image) ─► مرمِّز الصورة (Image Encoder) ─► متجه الصورة (Image Vector)
                              ╲
                               التشابه (Similarity)
                              ╱
النص   (Text)  ─► مرمِّز النص (Text Encoder)  ─► متجه النص (Text Vector)
```

[[IMAGE_NEEDED: CLIP contrastive learning | A batch of images and captions encoded into vectors with a similarity matrix; matching image-caption pairs highlighted along the diagonal and mismatched pairs shown off-diagonal | Learner should notice that training rewards matching pairs and separates mismatches]]

### تصنيف الصور بلا أمثلة (Zero-shot Image Classification)

أثناء Inference، يمكن كتابة Class Descriptions كنص:

```text
a photo of a transformer   — الوصف المرشح الأول
a photo of a robot         — الوصف المرشح الثاني
a photo of agi             — الوصف المرشح الثالث
```

تتم مقارنة Image Embedding بكل Text Embedding، وتصبح أقرب Text Description هي Predicted Class.

هذا يشبه Zero-shot Ideas التي درسناها سابقًا: يمكن لـ Natural-language Descriptions تعريف Classes جديدة من دون إعادة تدريب Dedicated Classification Head.

## مفاهيم خاطئة مهمة

### المفهوم الخاطئ 1: Scaling تعني زيادة Parameter Count فقط

> Bigger N وحدها كافية.

### لماذا هذا خطأ

يؤكد الفصل على Model Size وDataset Size وCompute Budget معًا.

### المفهوم الخاطئ 2: Sparse Attention تحذف Context ببساطة

> Efficient Attention Models لا تستطيع الاحتفاظ بـ Long-range Information.

### لماذا هذا خطأ

تجمع Sparse Designs بين Local وSelected Long-range/Global Connections بحيث يمكن للـ Model الاحتفاظ بالتفاعلات البعيدة المهمة مع تجنب حساب كل Pairwise Scores.

### المفهوم الخاطئ 3: Transformers تعمل فقط مع Text Tokens

> Attention تحتاج كلمات كـ Input.

### لماذا هذا خطأ

يمكن تمثيل Images كـ Pixels أو Patches، وAudio كـ Learned Feature Sequences، وTables كـ Structured Tokenized Inputs.

### المفهوم الخاطئ 4: Text-only Model لديها وصول مباشر إلى World Facts موثوقة

> إذا كانت الـ Model تنتج Fluent Language، فهي Factual Database.

### لماذا هذا خطأ

يشير الفصل بوضوح إلى أن Probabilistic Language Models قد تنتج Text غير صحيح Factually، وقد تفتقر إلى Grounding في Modalities أخرى.

### المفهوم الخاطئ 5: Multimodal Learning مجرد Concatenation لـ Raw Inputs

> أدخل Image Pixels وText Characters معًا وانتهت المشكلة.

### لماذا هذا خطأ

تحتاج Multimodal Systems الناجحة إلى Encoders وRepresentations وObjectives مناسبة لمحاذاة المعلومات بين Modalities.

| Band Attention | Attention مقيدة بمواضع Tokens القريبة |
| Dilated Attention | Attention على مواضع متباعدة وبينها فجوات |
| Random Attention | Attention إلى Sampled Subset من المواضع |
| الانتباه المحلي داخل الكتل (Block-local Attention) | Attention تتركز داخل Sequence Blocks محددة مسبقًا |
| Linearized Attention | Reformulated Attention تتجنب Explicit Quadratic Interaction Pattern التقليدية |
| ViT | Vision Transformer تستخدم Image Patches كوحدات شبيهة بالـ Tokens |
| TAPAS | Transformer Model للتفاعل باللغة الطبيعية مع Tables |
| ASR | التعرّف الآلي على الكلام (Automatic Speech Recognition) |
| wav2vec 2.0 | Self-supervised Speech Representation Model تحتوي على Transformer Context Layers |
| Multimodal Model | Model تجمع أكثر من Data Modality |
| LayoutLM | Model تجمع Text وVisual وLayout Information لفهم Documents |
| Contrastive Learning | Objective تقرّب Matching Representations وتباعد Mismatches |
| CLIP | Image-text Model تم تدريبها باستخدام Contrastive Alignment |
